## 要解决什么（承接痛点卡）

把"数字算完 → 还要写两遍（给学校 / 给家长）+ 排版做图"这段最耗神的转写劳动，变成"**拿着上一句算好的数，直接把两份报告写出来**"。
- 给**学校**：四段式 Word 报告，约 800 字，结论清楚、有建议。
- 给**家长**：HTML 图表版，看得懂、有图有真相。

## 手册原文指令（照着执行，不擅自改）

**① Word 报告：**
> "基于上面的分析，写一份班级成绩分析报告：班级整体情况、各科表现对比、需要重点关注的学生名单、下一步教学建议，800字左右。"

**② HTML 学情报告：**
> "把这次成绩做成一份HTML学情报告，带图表：成绩总览、各科对比、进步退步学生、知识薄弱点，适合发家长看。"

## 最终交付物清单

1. `输入素材/高一3班期中成绩.xlsx` —— 原表副本（本案直接复用案例05-1 的同一份数据）。
2. `阶段1_Word报告/` —— ① 班级成绩分析报告（`.docx`）；产物 + 阶段记录。
3. `阶段2_HTML图表报告/` —— ② HTML 学情报告（`.html`，带图表）；产物 + 阶段记录。
4. `最终产物/班级成绩分析报告.docx` —— 四段式 Word 报告（A4，含附表一/附表二）。
5. `最终产物/高一3班期中成绩学情报告.html` —— 单文件 HTML，内联 SVG 图表，含成绩总览、各科对比、分数段分布（知识薄弱点）、偏科情况、前10/后10 与班均之差、需要关注的学生、给家长的建议。
6. `过程记录.md`、`审查配置/reviewer-brief.md`、`自检表.md`。

## 内容口径（写死，供审查与复核）

- **数字同源**：两份报告的所有数字均来自 `_work/analysis.json`（案例05-1 已复算并核对过），**不在本案重新手抄**。
- **Word 报告四段**：① 班级整体情况 ② 各科表现对比 ③ 需要重点关注的学生名单 ④ 下一步教学建议。
- **重点关注学生三类**（从真实数据算出，非手写）：
  - 基础薄弱型 = 3 科及以上不及格（实算 6 人）
  - 严重偏科型 = 最高科与最低科分差 > 40 分（实算 17 人）
  - 高分偏科型 = 总分 ≥ 360 且存在不及格科目（实算 13 人）
- **HTML 图表**：共 4 张图 —— 各科平均分（柱状图）、各科分数段分布（热力图）、偏科生最高分vs最低分（哑铃图）、前10名与后10名总分与班均分之差（双向条形图）。
- **"进步退步"**：素材只有一次考试，**算不出来** → 显式替代为"与班均分的距离 + 偏科分差"，并在报告中写明原因（见痛点卡【补全】）。

## 验收点（供自检与审查）

- [ ] Word 报告含齐四段（整体情况/各科对比/重点关注名单/教学建议）。
- [ ] Word 约 800 字，A4，能被 Word 打开。
- [ ] HTML 报告含齐手册四要素（成绩总览/各科对比/需要关注的学生/知识薄弱点）。
- [ ] HTML **真的有图表**（不是只有文字），浏览器打开能看到图。
- [ ] 两份报告数字**同源且一致**，与案例05-1 复算结果一致。
- [ ] "进步退步"缺失一事**显式说明**，未编造数据。
- [ ] HTML 适合发家长：中文不乱码、手机能看、无外部依赖（单文件）。

## 红线

- 不许编造任何成绩数字；不许编造"进步退步名单"。
- 不许只描述不产出；`最终产物/` 必须有真能打开的 `.docx` 与真能看图的 `.html`。
