## 四、手册已给的锚点（照着对齐，不另起炉灶）

1. **两个知识点**（手册原文指定）：化学方程式配平、物质的量计算。
2. **手册给的题目样例**（**必须收录，作为对齐锚点**）：
   - **第9题 进阶 ★★★★☆**："将 5.85 g NaCl（摩尔质量 58.5 g/mol）溶于水配成 100 mL 溶液。求：（1）NaCl 的物质的量；（2）该 NaCl 溶液的物质的量浓度；（3）从中取出 10 mL 溶液，其中含有多少个 Na⁺ 离子？"（答案：0.1 mol；1.0 mol/L；6.02×10²¹ 个）
   - **第10题 挑战 ★★★★★**："实验室用大理石（主要成分 CaCO₃）与稀盐酸反应制取 CO₂，反应方程式为 CaCO₃ + 2HCl → CaCl₂ + H₂O + CO₂↑。现称取 25 g 含 CaCO₃ 质量分数为 80% 的大理石（杂质不参与反应），与足量稀盐酸充分反应。已知 M(CaCO₃) = 100 g/mol，M(CaCl₂) = 111 g/mol。求：（1）参与反应的 CaCO₃ 的物质的量……"（答案：0.2 mol；4.48 L；22.2 g）
3. **手册的解析写法**（照它学）：先给答案，再"→已知：… →（1）求…：公式 = 代入 = 结果"，最后给"关键概念"一句（例："溶液是均匀的，取出一部分溶液，浓度不变（仍为1.0 mol/L），但物质的量按比例减少。浓度是溶液的固有属性，不因取出量改变。"）。
4. **手册的知识点来源**：化学 19 人不及格（47.5%），"建议重点复习化学方程式配平、物质的量计算等基础知识"。

## 五、本案例自加要求（来自任务卡，非手册）

- **难度阶梯要显式标注**（★–★★★★★），并把基础/进阶写进题号行，方便老师按层挑题。
- **留作答空间**：配平题留 1–2 行、计算题留 4–6 行作答线（手册样例是让学生写完整过程的题，必须有地方写）。
- **答案与解析分段**（题目在前、答案另起一节），使同一份文件既能当学生卷、也能当教师版。
- **强制程序化校验**（本案最严的一条）：每个化学方程式校验原子守恒、离子方程式加校验电荷守恒、每道计算题独立复算——因为"题目出错"的负收益大于不出题。
- **附"命题说明（教师用）"**：写清对应薄弱点、难度阶梯、建议用法、与教材衔接，让别的老师拿到也能用。
