# 痛点卡 · 办公-13 多文档综合：提取共同主题生成综合报告

> 案例来源：《100+ WorkBuddy 通用指令》**「高级技巧提示词 · 1. 组合指令」多文档处理**
> 复刻日期：2026-10-12

## 一、痛点原句（引用手册原文）

**手册出处：** M1 高级技巧提示词 → 组合指令

> **多文档处理：** 同时处理[文档1]、[文档2]、[文档3]，**提取共同主题，生成综合报告**

**提取说明：** 手册此处是**一条指令模板**（把 `[文档N]` 当占位符），**没有**第二人称痛点导入、没有代价句、没有案例展开。按《子Agent执行规范》第〇补节，痛点提取的三个位置（章首导入 / 案例引入 / 章末收束）在本案例均缺位。因此本卡的痛点主体为 **【补全】**，仅"要解决什么任务"（多文档→共同主题→综合报告）引自原文。

> 同一节 M1 的自述也点了痛点的根：**`原文`「过于简略：信息不足导致理解偏差　过于复杂：信息过多影响处理效率」**——多份材料一起丢进去，人容易"只逐份复述"，综合不出"共同主题"。

## 二、痛点主体（【补全】）

**谁：** 手里压着好几份**同主题材料**、要写一份**向上汇报 / 跨部门对齐**的综合报告的人（本案例取"要给管理层写季度跨部门综合分析的运营负责人"）。

**真实场景：**
季度末，市场部、客服部、研发部各交了一份 Q3 季度总结（3 份 docx）。现在要写一份**跨部门综合报告**，向上汇报"这个季度全公司到底跑出了什么"。这不是把三份拼在一起，而是要**从三份里提炼出共同的东西**：

| 步骤 | 手工做法 | 代价 |
|---|---|---|
| 1. 逐份读 | 3 份报告从头读到尾，记住各自的数字与结论 | 每份 10 分钟，**3 份 30 分钟** |
| 2. 划重点 | 每份划出成果 / 问题 / 计划 | 手工标记，容易一带而过 |
| 3. **找共同主题** | 把三份的重点**横向对齐**，找出**跨部门重复出现的主题** | **最费脑**：要在三份不同部门的话术里认出"这其实是同一件事" |
| 4. 找差异点 | 认出三家**侧重不同**的地方 | 容易写成"每份都重要"，等于没差异 |
| 5. 配出处 | 每个论点标注**来自哪份报告** | 手工回翻，费劲且易错 |
| 6. 成文 | 写成一份有结论、能汇报的报告 | 又一轮写作 |

**旧做法的代价：** 3 份报告对读、提炼共同主题、写成综合报告，**人工要 2 小时左右**（逐份读 + 横向对齐 + 写作）。而且最容易犯的错是**只写出"每篇讲了什么"**——三段各讲一份，**就是没有"共同主题"**，等于把综合报告写成了三份摘要的拼接。材料越多（4 份、5 份），横向对齐的难度是**乘法级**上升。

**想要的目标：** 把 3–5 份同主题材料丢进去，直接拿到 **一份综合报告**：**① 共同主题（跨文档重复出现的，每条标注来源文档） ② 差异点（各家侧重不同之处） ③ 结论与建议**。不是"学会写综述"，是"**这份综合报告已经写好了，能交上去了**"。

**【补全】为什么值得解决：** 综合报告的真实价值在"**横向对齐**"——把散在各份材料里的**共同信号**提出来，让管理层一眼看到"公司层面在发生什么"。手工 2 小时里，真正耗人的是**"从三份不同部门的话术里认出同一件事"**这一步，也是最容易出错、最该交出去的一步。而且这活儿**每个季度、每个月都来一次**：**一次固化出归纳口径，下次换几份材料重跑一次即可**。

## 三、价值归类

**目标导向 ✅**

要解决的是"**必须交出一份提炼出共同主题、标注了出处的跨部门综合报告**"这个业务目标。
反面想想就清楚——如果只做成"教你怎么写综述"或"一个报告模板"，那是**工具理性**，本卡不通过。

## 四、本案例的"易错点"（复刻时特意守住，用来验证痛点是真的）

复刻时，从"多份报告 → 综合报告"这一步最容易出这三种错，产物必须逐条守住：

1. **只复述、无综合**：综合报告**必须提炼出跨文档共同主题**，而不是"市场部讲了A、客服部讲了B、研发部讲了C"的三段拼接。检验法：看每个"共同主题"是否**至少引用了 2 份（最好 3 份）文档**。
2. **无出处、不可回溯**：每条共同主题/差异点都要**标注来自哪份报告的哪条**，否则"看起来有观点、其实没依据"。检验法：抽查一条主题，能回原报告找到对应原文。
3. **数字张冠李戴**：三份报告各有数字（CAC、CSAT、交付率…），综合报告引用时**不得串号、不得编造**。检验法：抽查每个数字，必须在它标注的那份报告里找得到。

第 1 条是最关键的：**"每篇讲了什么"和"共同主题是什么"长得很像**，人一顺手就写成了前者。本案例产物的第一章就是"共同主题"，且每条**强制挂 ≥2 个来源**。
