## 输入素材

`输入素材/` 下 3 份同主题报告（自造，均为"云启科技 2026 Q3"）：

| # | 文件 | 部门 / 负责人 |
|---|---|---|
| 1 | `市场部_2026Q3季度总结.docx` | 市场部 / 周敏 |
| 2 | `客服部_2026Q3季度总结.docx` | 客服部 / 孙涛 |
| 3 | `研发部_2026Q3季度总结.docx` | 研发部 / 郑凯 |

- 三份**主题相关、各有侧重**：都涉及 **AI 落地 / 客户体验 / 降本增效 / 数据驱动**（可提炼共同主题），但侧重与问题**各不相同**（可提炼差异点）。
- 每份都带**可核对的数字**（如 CAC、CSAT、交付率），用于验证"综合报告不编造、不串号"。
- **刻意守住的三个易错点**：① 必须真正"综合"，不是三段复述；② 每条共同主题/差异点**标注来源**；③ 数字**不串号、不编造**。

> 手册为一条指令模板（`[文档1][文档2][文档3]`）。本机**无 WorkBuddy 插件**，按任务书要求用等价链路复刻：**docx（读 3 份）+ 综合归纳（Agent 语义）+ docx/md（出报告）**。

## 验收点（自检表逐条对应）

1. **2 类交付物真实落盘、能打开**：docx 可开且 A4；md 可开——**不许只描述不产出**
2. **真的"综合"**：报告第一章为"共同主题"，**每条共同主题至少引用 2 份文档**（不是三段复述各讲一份）
3. **差异点齐全**：明确指出三家**侧重不同**之处（至少 3 条）
4. **报告的每一章都落到"结论"**：有一章"结论与建议"，且据此推出跨部门协同重点
5. **每条论点标注来源文档**（可回溯：抽查一条能回原报告找到原文）
6. **数字不串号、不编造**：抽查每个数字，必须在它标注的那份报告里找得到
7. **docx 与 md 同源一致**
8. 按手册步骤顺序执行，未跳步；未擅自增加手册没要求的形态

- 不做 PPT（手册该条只要求"综合报告"）
- 不做"自动抓取报告"（3 份报告已是输入）
