# 讲课大纲 · 案例04-3 形态三·互动课件

> 本案例在手册中只有"形态三"一个小节 + 一段可直接复制的指令，没有分步教案。
> 按其主题与四件套指令法，把案例如何展开写明如下。

## 一、案例在章节中的位置

第04章主张"课件不只有PPT"，同一个"分数加减法"知识点配齐四种形态：
形态一 PPT（放着看的）→ 形态二 HTML（会动的）→ **形态三 互动课件（学生能上手的）** → 形态四 知识卡片（课后带走的）。
形态三承上启下：把形态二的"老师演示"推进到"学生上手"。

## 二、这节课怎么讲（案例自身的教学展开）

素材：五年级数学《分数加减法》第2课时 · 异分母分数加减法（4课时单元中的第2课时）。
学生基础：已学同分母加减、约分、通分。
重点：通分→计算→约分；难点：理解通分的必要性、会找最小公倍数作公分母。

| 环节 | 时长 | 做什么 | 用互动课件的哪部分 |
|---|---|---|---|
| 导入 | 5' | 分蛋糕情境：1/2+1/3 怎么算？先别算，先"看" | 【通分实验室】拖 1/3、1/4 的条到 12 等分格子 |
| 新授 | 15' | 通分→计算→约分；对比同分母与异分母 | 实验室的"看算式"揭示 4/12+3/12=7/12 |
| 练习 | 12' | 基础题 + 易错题，学生上台在**一体机**上点选 | 【闯关练习】Q1–Q7，即时反馈 + 错因提示 |
| 小结 | 5' | 口诀：先通分，再计算，能约分的要约分 | 页首口诀横幅；答错时的针对性提示回扣口诀 |
| 随堂检测 | 3' | 1/4+1/6、5/6−2/3 | 对应 Q1、Q4 |

## 三、形态三 vs 形态二（案例要讲清的差别）

- 形态二：老师点着翻页，动画演示计算步骤——**学生是观众**。
- 形态三：学生自己拖分数条、自己点答案、错了当场知道错在哪——**学生是操作者**。
- 一句话点题（手册原话）："形态二老师演示，形态三学生上手。"

## 四、给 WorkBuddy 的指令（四件套：我是谁·要什么·有啥料·要啥样）

**手册可直接复制的原句**（逐字）：
> "我是五年级数学老师，做'分数加减法'的互动课件：出几道异分母加减的练习题，学生能拖动分数条操作、点选答案，对错有即时反馈，适合课堂投屏。"

**本案例按四件套补齐的完整版**（供讲解对照）：
> 我是谁：五年级数学老师，学生刚学完通分。
> 要什么：做"分数加减法"的**互动课件**（可交互练习页，不是翻页演示）。
> 有啥料：异分母分数加减；重点通分→计算→约分；难点是理解通分的必要性、找最小公倍数；易错点三个：公分母找错、忘记约分、只通分母忘通分子。
> 要啥样：单文件 HTML，浏览器双击就开、离线可用；学生能拖动分数条、点选答案；对错即时反馈、错了提示错在哪；字号大按钮大，适合课堂投屏和一体机。

## 五、案例展开步骤（照做顺序）

1. **领任务**：读第04章形态三，提取痛点 → 痛点卡、任务卡。
2. **备弹药**：找 skill（web-artifacts-builder / algorithmic-art 自绘交互）→ skill清单。
3. **设计**：定题目清单（含每个错选项的错因）、定交互（拖拽怎么玩、反馈怎么给）→ 阶段1设计稿。
4. **开发**：按设计稿写单文件 HTML → 阶段2。
5. **联调**：headless Chrome 渲染截图 + 注入 JS 跑判定逻辑 → 联调记录。
6. **自查交审**：自检表打勾 + 审查 Agent 复审结论。
