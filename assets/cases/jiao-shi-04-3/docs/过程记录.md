## 一、踩过的坑（如实记录）

| # | 坑 | 定位 | 处理 |
|---|---|---|---|

## 二、【替代】汇总

1. **`web-artifacts-builder` → 手写单文件 HTML + 内联 CSS/JS**：理由是交付红线"单文件、双击即开、离线、零依赖"优先于"用上某个 skill"（规范三：不允许为了用 skill 牺牲红线）。替代方案即 `algorithmic-art` 的"自绘交互"精神。
2. **WorkBuddy 专属插件 → 手工等价实现**：本机无 WorkBuddy，按规范六"用最接近的等价方式替代并标注"。
3. **飞象老师（手册点名的替代工具）→ 未采用**：需注册 + 联网；按"不许假装做了"，只记录线索，不产出假截图。
