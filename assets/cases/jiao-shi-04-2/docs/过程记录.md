## 遇到的坑（全记录）

| # | 坑 | 现象 | 怎么发现 | 怎么解 |
|---|---|---|---|---|
| 1 | `__playSlide(i)` 不翻页 | 逐页截图 10 张全是第 1 页 | 截图内容一模一样，且我在日志里打印了 `deck.style.transform`，全是 `translateX(0vw)` | 读模板 JS 发现导航函数是 `go(n)` 且**没挂到 window**；改为点击 `#nav .dot`。修完 transform 逐页推进到 `-900vw` |
| 2 | Chrome 远程调试起不来 | `node qa_shots.mjs` 报 "chrome devtools not ready" | 手动起 Chrome 同参数却能通 | profile 目录建在输出目录里 + `stdio:'ignore'` 看不到报错；改为临时目录 + 收 stderr |
| 3 | 平铺质检页失效 | `--window-size=1440,9000` 截图里每页都变成 9000px 高 | 截图尺寸 1440×9000，但内容只有第 1 页 | `vh` 跟着视口走，平铺方案必须用固定 px；且 page 内元素仍用 vh，强行平铺会把 6vh padding 变成 540px。**结论：放弃平铺，改用 CDP 逐页翻页截图**（最终方案） |
| 4 | `merge_deck.py` 不幂等 | 重跑合并会把 slides 插两遍 | 脚本读 `ppt/index.html`（已是合成结果）当模板 | 改为**每次从 skill 的 `assets/template.html` 重新合成** |
| 5 | `.step-desc` 投影太小 | 1440px 下 ≈13.7px | 看 `contact-sheet.png` 里 P5 的步骤说明几乎读不清 | 补充样式抬到 `max(16px,1.15vw)` |
| 6 | `✗`/`✓` 有 emoji 字体风险 | 本机渲染正常，但 Windows 可能落到 Segoe UI Emoji 变彩色图标 | skill checklist P0"用 Lucide，不用 emoji" | 改为纯文字"错解 / 正解" |

## 与手册预期的差异（汇总）

1. **形态二"原生路径"无法复刻**（本机无 WorkBuddy 客户端）→ 走手册同形态的"技能包增强"路径。**不构成跳步**。
2. **风格参数选择与手册举例不同**：手册举例"瑞士柠檬黄风格"，本案例用"电子杂志风 + 靛蓝瓷"。手册原文为可选偏好。理由：本课是概念讲解、无数据支撑，风格 B（瑞士）的 KPI/矩阵版式用不上；靛蓝瓷更贴数学课的理性观感且投影对比清晰。
3. **手册未给本形态的页数骨架**（骨架表只出现在形态一）→ 本案例按备课素材的教学过程框架自行分页，页页标注素材出处，未自编内容。
4. **"离线可用"要说清楚是哪一种离线**（**这是本案例相对手册最有价值的实测发现**）：
   - 手册说"浏览器双击就能开"—— 联网时完全成立，且**会动**。
   - 但**断网 + 双击**时，动效引擎加载不到（`file://` 禁 ES module），入场动效与 P5 逐步点亮失效；**内容与翻页仍完全正常**。
   - 手册在形态二并未讨论离线，也没提示这一点；本案例用 `qa_offline.mjs` 把它实测出来并如实登记，同时给出"本地 http 服务"这一解法。
   —— 结论：**手册的"会动"成立，但前提是有网（或起本地服务）**。这一点值得写进我们自己的手册下一版。
5. **手册提醒"偏'演示感'，表格数据多还是用原生或PPT"**：本课无表格数据，不触发该限制。
