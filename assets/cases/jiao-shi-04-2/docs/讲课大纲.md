# 讲课大纲 · 案例04-2（HTML 网页课件怎么在课堂上用）

> 手册在本案例只给了主题与一句四件套指令，没有逐步流程；本文件把"这节课怎么用这个课件讲"写清楚，方便审查与迁移。

## 一、案例如何展开（复刻视角）

手册在本形态给出的路径有两条，本案例走第二条（技能包增强）：

| 路径 | 手册原话 | 本案例 |
|---|---|---|
| 原生路径 | "它会生成一个单文件HTML 网页，浏览器双击就能开，←→翻页，动画演示计算步骤。" | 对照记录 |
| **技能包增强** | "可以装一个技能包增强，比如「guizang-PPT-Skill」……它生成单文件HTML，←→翻页演示，手机、一体机都能用，风格比原生精致。" | **本案例采用** |

手册还提示风格可指定："可以在输入提示词的时候直接加上风格参数，比如在前面的提示词的最后加上'瑞士柠檬黄风格'。"
本机同款 skill 提供两大风格系统（风格A 电子杂志风 / 风格B 瑞士国际主义）。本案例选 **风格 A · 电子杂志风**，主题色 **🌊 靛蓝瓷**，理由见 `阶段1_大纲与风格/风格与节奏规划.md`。

## 二、课堂使用节奏（40 分钟一节课）

| 时段 | 页码 | 做什么 | 课件的角色 |
|---|---|---|---|
| 0–5′ 导入 | P1–P3 | 从"分蛋糕"抛出 1/2 + 1/3；先复习同分母，再暴露冲突 | P3 的**分数条**是本课第一个"看得见"的点：两条条子格子不一样大，学生自己发现"不能直接加" |
| 5–12′ 建立方法 | P4–P5 | 通分 → 计算 → 约分，三步定型 | P5 流水线**逐步点亮**（按 → 一次亮一步），老师讲一步点一步 |
| 12–22′ 例题示范 | P6 | 1/3 + 1/4 与 3/4 − 1/6 完整板书 | P6 巨型分数算式，投屏后排可读；老师让学生先说下一步 |
| 22–28′ 易错点 | P7 | 三个坑，逐条对照"错解/正解" | P7 三张卡并列，对照式呈现，比口头强调更记得住 |
| 28–38′ 随堂练习 | P8–P9 | 基础关 3 题动笔；挑战关 2 题 + 答案揭晓 | P8 留白让学生上黑板；P9 答案页，先不给答案、学生答完再翻 |
| 38–40′ 小结 | P10 | 口诀收束 | P10 金句页，让学生齐读一遍 |

## 三、操作提示（老师用）

- **翻页**：`← →` 或滚轮或触屏滑动；`ESC` 打开索引视图跳到任意页。
- **静态模式**：按 `B` 切到低功耗模式（停掉 WebGL 背景与入场动画）——**一体机性能弱、或投影时画面卡，按一下 B**。
- **P5 流水线页**：这一页的箭头/空格是"逐步点亮"而不是翻页，三步点完才翻下一页。
- **建议全屏**：浏览器按 `F11`，投屏后按 `ESC` 索引可快速跳页。

### 断网时怎么办（已实测，不是猜的）

| 情形 | 会怎样 | 老师要做什么 |
|---|---|---|
| 教室有网（最常用） | 完全正常：衬线字体、WebGL 背景、翻页入场动效、P5 逐步点亮**全都在** | 不用管 |
| 教室没网，直接双击打开 | **内容完整、翻页正常、中文与分数都清晰**；但**入场动效与 P5 逐步点亮会失效**（该页三步一起亮出来，改成老师口头一步步讲即可） | 照常上课；P5 改成口头分步 |
| 教室没网，又想要动效 | 用本地 http 服务打开就有动效（本地 `assets/motion.min.js` 这时才生效） | 在课件文件夹里开一个终端跑：<br>`python -m http.server 8000`<br>然后浏览器访问 `http://localhost:8000/分数加减法_HTML课件.html`（需与 `assets/` 同级目录） |

> 上表由 `qa_offline.mjs` 断网体检实测得出（拦掉全部外部 CDN 后逐页翻页截图 + 收控制台异常）：翻页 10/10、内容 10/10、无未捕获异常。证据见 `最终产物/质检/断网形态/` 与 `过程记录/离线体检输出.txt`。
> 根因：动效引擎 `motion.min.js` 是 ES module，浏览器不允许从 `file://` 直接加载，所以"双击打开 + 断网"这一组合拿不到动效——这是所用模板（guizang-ppt-skill）的固有行为。

## 四、与形态一的对照（讲给老师听的话术）

同一句"我是五年级数学老师，要一节'分数加减法'……"，
- 形态一出来的是 **6 页 .pptx**，能改、能打印、能放进学校的课件规范里；
- 形态二出来的是 **一个单文件 .html**，双击就开，翻页会动，分数条能"长出来"。

**内容一样，壳不一样。** 这就是"新形态课件"：不是换个软件，是给同一个知识点配不同的装备。
