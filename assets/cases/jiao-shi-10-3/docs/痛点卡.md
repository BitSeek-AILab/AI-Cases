# 痛点卡 · 案例10-3 课件选中就统一（人机双写·课件）

> 依据：`子Agent执行规范.md` 第〇节「痛点先行」+ 〇补「痛点提取细则」
> 出处：`手册Markdown/第10章/第10章.md`（场景三：人机双写·课件，选中就统一）

## 一、痛点原句（引用手册原文）

**位置1 · 案例引入（第10章「场景三：人机双写·课件，选中就统一」）：**

> "第04章，你学会把课件做成四种形态。**但PPT做到一半，最常见的问题不是'做不出来'，是风格不统一：这页米白底、那页带浅蓝，标题颜色各管各。**
> **以前，要么一页一页手动调，要么重新生成。现在，选中就改。**"

**位置2 · 案例内的实测提示（手册原文，本案例的"选中区"依据）：**

> "先说一个 PPT 里的实测发现：「AI编辑」认的是'**选中的内容**'，不是'选中的整页'。选中整页不一定会弹按钮，但**选中这一页里的标题或文字**，按钮就出来了。所以操作是：**选内容，让AI改。**"

**位置3 · 案例的价值收束（手册原文）：**

> "课件做到这个程度，就不再是'**能投屏**'，而是'**讲得顺**'。"

**位置4 · 章末收束（这一章记住三件事）：**

> "人机双写=框选即改：先选中，点「AI编辑」，输指令。教案、成绩、课件，框到哪改到哪，改完可核对。"

## 二、痛点主体

- **谁**：五年级数学老师（本次复刻的具体身份；素材就是五年级"分数加减法"的课件）。
- **场景**：一份 **5 页的半成品课件**，做到一半——**5 页背景色各不相同**（米白 / 浅蓝 / 浅绿 / 浅橙 / 灰），**标题颜色也各管各**（深蓝 / 深靛 / 绿 / 橙 / 深灰）。

## 三、旧做法的代价

- **旧流程两条路**（手册原文）："**要么一页一页手动调，要么重新生成。**"
  - **一页一页手动调**：逐页选中标题 → 改颜色 → 再逐页点背景 → 设填充色；5 页就是 **10+ 次点击**，且**改了第 3 页忘了第 5 页**是常事。页数一多，成本线性上升。
  - **重新生成**：等于**把已经做好的内容全部丢掉重来**——那 5 页上已经写好的例题、答案、排版，全白做。
- 【补全】真正的代价不在"改颜色"这件事本身（改一个颜色只要 3 秒），而在**"风格不统一"这件事很难被穷尽地发现和修完**：老师是**边做边发现**的——做到第 4 页才发现"咦，第 2 页底色好像不一样"，这时回头改，又容易漏。于是最常见的结局是**凑合着用**：一份"内容没问题、看着不专业"的课件。而这份课件是要**投屏给全班、公开课给评委、家长会讲给家长**看的。

## 四、想要的目标（做到什么程度算"解决好"）

- **选中一处 → 一句指令 → 整份跟着统一**（不用一页页调、不用重做）。
- 手册给的三条指令逐条落地：
  - **基本**："把整份 PPT 的标题统一成这个样式：**蓝色、加粗、字号一致**。"（选中第 1 页标题）
  - **进阶一**："**按这一页的配色，把整份PPT的背景颜色和文字统一成同一套风格。**"（选中某一页的标题或正文）
  - **进阶二**："**按这页内容写30秒演讲备注，语气像对着家长讲话，别太书面。**"（选中某一页内容）
- **一条隐含红线**：统一的是**样式**，不是**内容**——5 页上的例题、答案、文字，**一个字都不能变**。
- 目标状态（手册原话）：从"**能投屏**"到"**讲得顺**"。

## 五、【补全】

【补全】手册说清了"一页页调很烦"，但没讲透**为什么"风格不统一"值得专门做一个功能**：

- **课件的第一印象是"专业度"，而专业度几乎全由"一致性"承载**。同一份课件里背景色跳变、标题色跳变，学生的第一反应不是"这页颜色挺好看"，而是"这份课件是不是拼的"。**不一致本身就是信号**——它告诉听众"这份东西没被认真做完"。
- **而"一致"这件事，人手工做不可靠**。人对相近颜色的分辨力有限（尤其投影仪偏色的情况下），靠肉眼逐页比对，**漏掉一两页是常态**。这正是"AI 属性级统一"比"人手调"根本强的地方：它比的是**色值**，不是眼睛。
- **手册把"30 秒演讲备注"和"统一风格"放在同一个场景里，是有讲究的**：统一风格解决"**看起来**是同一份课件"，演讲备注解决"**讲起来**是同一份课件"。前者管视觉一致，后者管**话术一致**——合起来才是手册那句"不再是能投屏，而是讲得顺"。

## 六、价值归类

✅ **目标导向**：老师要的是"**这份课件投出去、讲起来像一份认真做完的东西**" → 所以统一风格 + 补上演讲备注。
❌ 非"工具理性"（不是为了"我有个 PPT 所以找个 AI 优化它"）。
