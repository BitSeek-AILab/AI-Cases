# 讲课大纲 · 案例10-3 课件选中就统一（人机双写·课件）

## 一、本案例在手册里的位置

第10章「场景三：人机双写·课件，选中就统一」，是四个场景里的第三个。

三个场景的递进关系很清楚：
- 场景一（教案）：**文字**——框一段改一段；
- 场景二（成绩）：**数据**——圈一片做分析、出图；
- **场景三（课件）：格式/样式**——**选中一处，整份跟着统一**（本案例）；
- 场景四（集体备课）：把前面这些放大到多人协作。

所以本案例是"框选即改"第一次作用在**格式**上：改的不是文字内容，是**样式属性**（颜色/字重/字号/背景）。

## 三、手册已给的锚点（照着对齐，不另起炉灶）

1. **痛点原文**："PPT做到一半，最常见的问题不是'做不出来'，是风格不统一：这页米白底、那页带浅蓝，标题颜色各管各。以前，要么一页一页手动调，要么重新生成。现在，选中就改。"
2. **"选中内容"而非"选中整页"**（原文）："'AI编辑'认的是'选中的内容'，不是'选中的整页'。选中整页不一定会弹按钮，但选中这一页里的标题或文字，按钮就出来了。所以操作是：**选内容，让AI改。**"
3. **三条指令原文**：基本（标题统一：蓝色/加粗/字号一致）、进阶一（按这一页的配色统一全份）、进阶二（30 秒演讲备注，对家长讲话）。
4. **手册的四步操作**：①打开 PPT ②在某一页里选中标题文字（比如第1页的"分数加减法"）③点「AI编辑」输指令 ④发送，再到对话区点一次"发送/执行"。
5. **手册的价值判断**："课件做到这个程度，就不再是'能投屏'，而是'讲得顺'。"
6. **素材说明**（手册原文）："课件素材五年级数学分数加减法\_半成品.pptx（**可直接用**）"。

## 四、本案例自加要求（来自任务卡与规范，非手册）

- **视觉检查必须真做**（规范第五节：PPT/视觉类产物 → 调有视觉能力的审查方式，渲染/截图核对版式与观感）。本案例产出 `before-01..05.png` / `after-01..05.png` / 逐页对比图 / 对比总览，**做像素级差异统计**。
- **"内容一字未改"要可验证**：逐形状比对统一前后的文字，改动数必须为 0（防止"统一风格"变成"顺手改内容"）。
- **"统一"不等于"覆盖"**：5 页标题**文字必须各不相同**，只统一样式。校验里专门断言这一点。

## 五、讲这个案例时值得点出的三个细节

1. **为什么手册强调"选中内容，不是选中整页"**——这是这个功能的**入手点**。很多老师第一次用会先选整页，结果按钮不弹，以为坏了。讲课时要把这一句单独拎出来。
2. **"以选中内容为准"是这个功能的语义**：你在哪一页操作、选了什么，**它就以那个为模板**。本案例选第 1 页——因为第 1 页（封面）的配色最中性、最专业，适合当全份基调。**选哪一页是一个有讲究的决定**。
3. **"统一"的边界**：统一的是**样式属性**（背景/颜色/字重/字号），**不是内容**。这一点要反复强调——否则学员会担心"它会不会把我改好的例题也动了"。本案例把"内容改动数 = 0"做成了校验项。

## 六、和案例10-1 的对照（同一能力，不同对象）

| | 案例10-1（教案） | 案例10-3（课件） |
|---|---|---|
| 选中区 | 正文"导入"3 段落 | 第 1 页**标题文字** |
| 改的是什么 | **文字表达**（内容） | **样式属性**（格式） |
| "其余不变"的含义 | 其余文字一个字不动 | 其余内容一个字不动；且**未选中页的样式**是否跟着变——本案例按手册"按这一页的配色统一**整份**"的语义，**全份统一** |
| 验证方式 | 逐字符比对 XML | **渲染前后逐页比对（视觉）** + 逐形状文字比对 |

> 这一对照值得在课上讲：**同一个"选中即改"，对文字是"改内容"，对课件是"改样式"——判断标准不同，但"只动该动的"这条纪律是一样的。**
