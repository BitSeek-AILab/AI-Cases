## 二、⚠ 关键证据：这个案例的四条纪律

### 纪律 1 · AI 的改动**不直接进正文**（手册的设计核心）

手册原话："AI的改动**不会直接写进正文**，而是以'建议修订'一条条列出来，你逐条决定接受还是拒绝。**教研材料不会被AI悄悄改乱**。"

落地方式（可核）：
- **物理分离**：初稿正文在 `阶段1_…/…（初稿·AI扩写建议版）.md`，AI 改动在 `阶段2_建议修订/建议修订.md`，**两个文件**；
- **状态口径写死**：`采纳` → 才写进定稿正文；`不采纳` → 留在表里备查、**不进正文**；
- **五要素齐全**：每条含 提出人 / 原文 / 建议改为 / 理由 / **状态** → "逐条决定"才执行得下去。

### 纪律 2 · 三条组内意见**逐条落地**

| 意见 | 建议修订 | 定稿里的落点 |
|---|---|---|
| 王老师：导入加 2 分钟看图猜诗句 | R-01 | 环节一标题改"导入：看图猜诗句"，时间 **5′→7′** |
| 张老师：作业按分层设计 | R-02 | 第六节拆成 **基础/提升/拓展** 三层 + 上交批阅口径 |
| 陈老师：思政点落在"豁达"上 | R-03 | 第九节 **两处落点 + 边界句** |

### 纪律 3 · **时长守恒**（不能被"加一个环节"悄悄撑大）

R-01 给导入加了 2 分钟 → 从环节四（8′→7′）、环节五（7′→6′）各匀 1 分钟。
**定稿时间校验：7 + 8 + 12 + 7 + 6 + 5 = 45 分钟** ✅

### 纪律 4 · 发布前**脱敏体检**（手册明写的一步）

手册原文："发出去之前，检查一遍网页里有没有带学生的全名、电话、家庭住址，有就先脱敏再发。"

体检结果：**手机号 / 座机 / 身份证 / 邮箱 / 住址 五类扫描全部 0 命中**；15 个学生姓名为常见占位姓名（张三、李四…），页面定位 **班内可见** 故保留；**`--mask` 开关已做好**（张三 → 张＊），要外发时一个参数即脱敏。

## 三、技术处理（关键决策与坑）

### 决策 1 · 教案**故意用 Markdown，不用 docx**

手册自己讲明了理由："**选Markdown是有讲究的：AI后续改动会以'建议修订'逐条列出来**，教研材料不会被它悄悄改乱，这正好是集体备课要的。"
如果做成 `.docx`，就失去"建议修订"这一层。所以本案例**不放 docx 产物**——不是漏做，是为了对齐手册的设计意图。

### 决策 2 · 发布版里加了两处"学科专属"的内容

- **45 分钟时间分配条**（6 段宽度 = 实际时长）：一眼看出课时结构；
- **"乐 → 悲 →（喜）"情感线示意图**：把本课主线画出来，并标出"喜"属于第二课时。
这两处不是装饰，是**这节课真正的骨架**——手机上打开就能看懂"这节课怎么走"。

### 坑 A · Chrome 无头窗口有最小宽度，导致**误判"页面溢出"**

`--window-size=390` 实测 `innerWidth` **= 504**（Windows 无头最小窗口宽），截图只截了左边 390px → **右侧 114px 被裁**，看起来像横向溢出（图例被"截断"）。
**对策**：先做一份**约束到 390px 的探针副本**（注入 `html,body{width:390px}` + 溢出体检脚本），用 `--dump-dom` 读回 `scrollWidth` 与越界元素清单，再截图裁到 390。
**教训**：**截图裁剪和真实溢出长得一模一样**——必须用 `scrollWidth` 实测，不能靠看图判断。（第一次就误判了。）

### 坑 B · SVG 里 `fill="var(--x)"` 无效 → 示意图全黑

`var()` 是 CSS 自定义属性，**只在 CSS 声明里解析**；写在 SVG 的 presentation **attribute** 里会被忽略，`fill` 退回初值（黑），整个示意图变成黑块。
**对策**：全部改成 `style="fill:var(--joy)"` / `style="stroke:var(--rule)"`；数值型属性（`stroke-width`、`stroke-dasharray`）保持不变。

### 坑 C · 脱敏体检第一版**误报**

- 住址正则用了单字关键词（号/栋/室/路…）→ "各班**教**室"被判成住址；
- 姓名抽取从所有行抓 2—3 字词 → "月考""到校""假作业"被当成学生姓名。
**对策**：住址改成**门牌号式**正则（`\d+(号楼|号|栋|单元|室|层)`）或明确地名（小区/大厦/公寓…）；姓名**只从"值日/分组"两类行**抽取，并先剥掉"第N组/组长/组员"等前缀。修后 5 类扫描 0 命中、15 个姓名正确。

### 坑 D · Artifact 发布不可用（平台能力缺失）

尝试用 Artifact 工具发布发布版 HTML 以得到真实链接 → **被拒**：本会话以 `ANTHROPIC_AUTH_TOKEN` 鉴权，Artifact 发布要求 claude.ai 账号登录。按提示**未重试**。

### 坑 E · 环境类

- PowerShell 5.1 按 ANSI 读 `.ps1` → 脚本内不放中文注释；
- Chrome `--screenshot` 的相对路径不落在 shell 的 cwd → **必须传绝对路径**；
- Git Bash 对中文路径报错 → 涉及中文路径一律走 PowerShell。
