02教学目标

四条按语文核心素养四个维度展开，均可课后检测。

  1. 语言建构与运用：能读准"壬戌、窈窕、嫠妇、舳舻、酹"等字音，疏通第一、二段文言词句，积累"少焉""白露""纵一苇之所如""冯虚御风"等词句。
  2. 思维发展与提升：能说出作者情感的变化线（乐 → 悲），并用原文依据说明每一段"乐从何来""悲从何来"。
  3. 审美鉴赏与创造：能找出第一段写景的句子，说出"清风、白露、江水、明月"这组意象营造出怎样的境界。
  4. 文化传承与理解：初步体会苏轼在最失意处仍能"与江月同游"的豁达，理解这种态度的可贵。

03教学重难点

教学重点

  • 理清第一、二段的情感线索：由"乐"转"悲"是怎么发生的。
  • 读懂第一段"写景即抒情"——景不是背景，是心境。

教学难点

  • 情、景、理如何交融："悲"不是突然来的，它是从"乐"里面长出来的（越乐，越觉人生短）。
  • "变与不变"的哲理理解：本课时只作铺垫，完整的哲理讨论留在第二课时。

环节一 · 导入：看图猜诗句

7′
教师做什么

① 播放"赤壁江月"风光视频约 60 秒，不讲解。

② 看图猜诗句（2 分钟）：出示 3 张图（赤壁江月 / 秋江白露 / 孤舟明月），每张停约 20 秒。学生答出课文原句最好，答别的咏月诗也接住。

不用举手，想到就说——这三张图，让你想起哪句诗？

收拢："这些句子有个共同点——都是对着水和月写的。今天要读的这篇，也是。"

③ 苏轼三句话：他 21 岁考中进士，主考官说"我要避这个人一头"；他 44 岁被关进大牢 103 天，差点死在里面——就是乌台诗案；出狱后被贬到黄州，一个没有实权的闲官。《赤壁赋》就写在这个时候。

④ 抛问："一个刚从死牢里出来、被贬到偏远小城的人，写出来的东西，你猜是苦的，还是别的味道？"

学生做什么

看视频 → 看图联想、自由说诗句 → 听三句话 → 自由猜测回答（2—3 人）

设计意图 先用画面唤起诗句（零门槛、全班可参与），再用"反差"制造疑问：越惨的人越可能写出越开阔的东西——这个矛盾就是本课的入口。

环节二 · 初读正音

8′
教师做什么

① 布置自由朗读全文，圈出读不准的字。

② 出示易错字音：壬戌（rén xū）、窈窕（yǎo tiǎo）、嫠妇（lí fù）、舳舻（zhú lú）、酹（lèi）、少焉（shǎo）。

③ 请 2 名学生分段朗读第一、二段，其余学生对照课本圈出错处。

④ 齐读第一段。

学生做什么

自由朗读 → 圈注字音 → 2 人分段读 → 其余人带着"找错"任务听并纠正 → 齐读

设计意图 扫清字音障碍；给"听的学生"派任务，避免旁听走神。

环节三 · 精读第一段：写景与"乐从何来"

12′
教师做什么

① 抛问："第一段里，苏轼和朋友在做什么？请用原文回答。"（"苏子与客泛舟游于赤壁之下"——秋夜泛舟。）

② 追问："这一段写了哪些景？"引导找出：清风、白露、江水、明月。

③ 再追问："'乐'从哪里来？"收敛成两个词：景美 + 自由。

· 自由："纵一苇之所如，凌万顷之茫然"——想漂到哪就漂到哪（此句单独挑出来讲）。

· 景美："浩浩乎如冯虚御风""飘飘乎如遗世独立"——像要飞起来。

④ 板书情感线起点：乐 —— 景美 · 自由。

学生做什么

齐读第一段 → 圈画写景词句 → 回答、补充 → 批注"乐：景美 + 自由"

设计意图 把"写景即抒情"讲透：景写得越美，越说明此刻心里是松的——这是"悲"的对照面。

环节四 · 精读第二段："悲从何来"

7′
教师做什么

① 范读第二段，要求全班听"心里的变化"。

② 抛问："这一段，'乐'还在吗？"（不在了。）

③ 追问："悲从哪里来？"抓关键词："渺渺兮予怀，望美人兮天一方"（心里有个够不着的东西）；"其声呜呜然……如怨如慕，如泣如诉"（客的箫声是悲的）。

④ 点明："悲"不是突然来的，是从"乐"里面长出来的——越是觉得此刻好，越会想到这样的时刻不长久。

⑤ 板书情感线：乐 → 悲。

学生做什么

听读 → 圈出写"悲"的词句 → 回答讨论 → 批注"悲：人生短暂"

设计意图 让学生看到情感的转折机制，而不是把"乐—悲—喜"当三个孤立标签背下来。

环节五 · 小组讨论："悲"到底在悲什么

6′
教师做什么

① 出示讨论题："客悲的是什么？请从第二段里找依据，说出你的判断。"

② 四人为一组，分工：记录员、发言人、计时员、点评员。

③ 巡视，对卡住的小组给提示（回看"望美人兮天一方"和箫声那两句）。

④ 请 2—3 组发言，教师不急着评判对错，先把不同答案写在黑板上。

学生做什么

四人小组：找依据 → 讨论 → 记录 → 发言；其余组倾听并补充或质疑

设计意图 课堂互动第一处：把结论的生成权交给学生，老师只负责收敛。

环节六 · 小结与作业布置

5′
教师做什么

① 带全班回看板书情感线：乐 → 悲。

② 留悬念："悲到这儿就完了吗？没有。下节课看苏轼怎么从'悲'里走出来——那才是这篇文章最厉害的地方。"

③ 思政一句预告（见第九节）：

被贬到黄州的时候，苏轼写下了"清风徐来，水波不兴"。一个人在最难的地方，还能看见风和水——下节课我们就看他怎么做到的。

④ 布置作业（见第六节），说清交什么、什么时候交、怎么评。

学生做什么

齐读板书要点 → 记录作业条目

设计意图 小结"挂住下一课时"；作业分层可做；思政埋而不发。

备选互动 · "一句话说给苏轼听"

06作业设计

上交与批阅：全员下节课前交（课代表按组收齐）；基础层抽查、提升层全批、拓展层面批 2—3 份并下节课展示。

基础层 人人必做

  • 背诵《赤壁赋》第一、二段——下节课开头抽查（同桌互背 → 抽查 3 人）。
  • 抄写并解释下列词句：少焉、纵一苇之所如、凌万顷之茫然、冯虚御风、遗世独立。

提升层 选做，鼓励做

  • 仿照第一段写景手法，写一段身边的景（150 字左右），要求：① 至少写两处景；② 景中要能看出当时的心情（乐 / 悲 / 静 / 别的，都行）；③ 在段末用一句话说明"我借这个景写的是哪种心情"。

拓展层 学有余力

  • 查一查乌台诗案的经过，用 150 字说明：一个人在什么处境下，会写得出"清风徐来，水波不兴"这样的句子？

09思政融入："豁达"

落点一 · 本课时（环节六，一句预告，不展开）

"被贬到黄州的时候，苏轼写下了'清风徐来，水波不兴'。一个人在最难的地方，还能看见风和水——下节课我们就看他怎么做到的。"

落点二 · 第二课时（讲完"变与不变"后收束）

"苏轼没有说'我不难过'。他说的是：水一直在流，可它从没真正流走；月亮一直有圆缺，可它从没真正增减。换个角度看，得失本来就不那么绝对。"

边界句 · 必须讲

"苏轼的豁达不是不在乎，是看清了以后仍然在场——他该难过还是难过，只是没被难过困住。"

不从"我们要学习苏轼的乐观精神"这样的口号入手，而是从文本本身生发：学生读到"清风徐来，水波不兴"时那种"他怎么还能这么写"的震动，就是思政最好的入口。不贴"爱国主义 / 价值观"标签。
