## 三、发布版怎么用（"发布成链接"这一步）

1. 把 `赤壁赋第一课时教案_发布版.html` **上传到任意静态托管**（学校网站 / 对象存储 / 内部网盘），拿到链接；
2. 或者最省事：**直接把文件发到教研组群**，老师点开就是一个排版完整的页面——**手机也能看，不用装任何东西**；
3. 页面是**单文件、自包含**的：除了 Google Fonts（字体），不依赖任何外部资源；**离线也能打开**；
4. 页面自动适配**明暗两种主题**，手机上**不会左右滑动**。

> ⚠ **本机限制说明**：WorkBuddy 的"一键发布成链接"是平台功能，本机没有；本会话也无法调用 claude.ai 的 Artifact 发布（需要 claude.ai 账号登录，本会话用的是 API token 鉴权，调用被拒）。
> 所以这一步**降级为"产出可直接托管的单文件 HTML"**——**发布版的页面能力（手机可读、明暗可读、无横向滚动、离线可开）与手册要求一致**，差的只是"平台帮你生成链接"这个动作。

## 四、班级门户的用法与安全提醒

- **数据与页面分离**：门户页由 `班级事务素材_高二3班_值日分组通知.csv` 生成。**改表 → 重跑一次生成脚本 → 页面自动更新**（对应手册"我改表页面自动更新"）。
- **发布前已做脱敏体检**：手机号 / 座机 / 身份证 / 邮箱 / 住址 **五类扫描 0 命中**，无隐私字段。
- **姓名**：CSV 中均为常见占位姓名，页面定位"班内可见"故保留；**若要外发**，重跑生成脚本时加 `--mask` 即把姓名脱敏（张三 → 张＊）。
- **可见范围**：设置为「**仅班级成员可见**（发群/群文件，不公开）」。

## 五、这一份东西"活"在哪里（为什么不会再有版本混乱）

| 旧做法 | 现在 |
|---|---|
| 主备人发一版 → 王老师改一版 → 张老师改一版 → 谁也不知道哪份最新 | 全组打开**同一个共库**里的**同一份**文件 |
| 意见在群里，说不清"加没加进去" | 意见进**建议修订表**，有提出人、有理由、有状态 |
| AI 直接改正文，改错了查不到 | **改动不进正文**；只有"采纳"才写进定稿 |
| 定稿靠传文件 | 定稿**发布成链接/单文件页**，全组点开即看 |

> 手册对这件的说法是："**从'每人一版传来传去'，到'全组共用一份活档案'。**"
