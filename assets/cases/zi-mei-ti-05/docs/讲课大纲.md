# 讲课大纲 · 自媒体-05 公众号封面成对生成

> 本案例是"领域二 · 自媒体"的**封面环节**。教学主线 = **封面要"成对"，且"成对"不是"裁一刀"**。
> 材料只有一句能力描述（skill），下面把它拆成可讲的 4 幕 + 1 个"坑"。

---

## 教学主线（一句话）
**主封面和方封面是"两件作品"，不是"一张图的两种裁法"——比例不同，注意力预算就不同，标题都该重写。**
手册把这件事做成 skill（"21:9 + 1:1 成对编排"），本质是**把"比例 + 层级 + 品牌色"的排版决策固化**，人只交代主题。

---

## 四幕结构

### 第 1 幕 · 提需求（对应 skill 能力描述）
- 讲师口播：公众号每发一篇都要出两张封面，@AI——
  **「给我这篇公众号文章的成对封面：21:9 主封面 + 1:1 方封面」**。
- 落点：**这是一句"听起来简单、做起来天天翻车"的需求。**

### 第 2 幕 · 翻车现场（对应"尺寸被裁 + 全靠手感 + 20 张图"的痛点）★关键
- 讲师展示**错误示范**（本案例实测对比，见 `阶段1_封面规划/产物/封面规划.md`）：
  1. 把 21:9 长标题**硬塞进方形** → 在 1:1 上折成 3-4 行，像一段话，缩略图看不清；
  2. 把主封面**直接裁**一份当方封面 → 关键信息被裁掉；
  3. 两张**各自手拼** → 颜色/字级不统一，看着像两篇不同的文章。
- **教学点**：**"成对"的病根是"把两件作品当一次裁切"。** 比例不同 → 标题长度、字号、构图都得**重编**。
- 提问设计：*你在订阅号列表里，方封面小到只剩一个词——你希望那个词是什么？*

### 第 3 幕 · 派生短标题（对应 `title-shortener.md` 五步法）★主线
- 演示：**长标题先写，短标题后派生**——
  - 长标题（21:9）：`AI 工具的 5 个高频用法`（1 行，≤14 字）
  - 五步法：找核心动词（用）→ 找核心对象（AI 工具）→ 压到 4-10 字 → 去英文只留必要 → 必要时才加小副题
  - 短标题（1:1）：`AI 工具 / 5 个用法`（2 行，每行 ≤6 字）
- **教学点**：**"不许把 21:9 的标题原样塞进 1:1"**（skill Non-Negotiables）——方封面是**另一个句子**。

### 第 4 幕 · 各自编排出图（对应"成对编排"）
- **同一 HTML** 内放两张：21:9（标题在左安全区 + 右侧"5 条"系统块）/ 1:1（大字号居中、无图无副标题）+ 配对预览同框；
- **Chrome headless** 出 **2100×900 / 1080×1080 / 配对预览**，另导出**微信上传位 900×383**；
- **插桩核验**：尺寸 / 溢出 / 触边 / 标题字重。
- 收束（回扣领域二开篇）：**"比例对齐 + 成对出图"是重复劳动交给 AI；"封面钩子是什么"是判断，留给自己。**

## 本复刻的说明（讲课时要标）
- 内容：**自造**（`输入素材/主题与素材.md`），与 04 同一篇《AI 工具的 5 个高频用法》；**封面不含任何百分比/榜单**。
- 出图：`gpt-image` 本机无 key → 用 `guizang-social-card-skill` 种子模板 + **Chrome headless** 出图（标【替代】）。
- 尺寸：21:9=2100×900（skill 规范高清母版）；**另出微信实际上传位 900×383**（精确命中，本工程 01 案未出此版）。
- 核验：视觉 API 不可用 → **DOM/几何插桩**实测（尺寸/溢出/触边/字重），实测值记入 `核验实测.md`。

## 课后练习建议
让学员拿**自己的一篇文章标题**，先写 21:9 长标题，再用五步法派生 1:1 短标题，各自编排出一对。**重点练"给方形重写一个短标题"这一步**——不是裁图。
