## 要解决什么（一句话）
每发一篇要出两张比例不同的封面——**尺寸不对被裁、字号品牌色全靠手感、发 10 篇就是 20 张图还老重做**；本案例把"**长标题 + 派生短标题 → 同一 HTML 内各自编排 → 出 PNG → 插桩核验两个尺寸**"做成一次可复制的成对出图，产出**同一主题、两种构图、尺寸精确**的成对封面。

## 关键步骤（严格照 skill 的两条硬规则做实）

能力描述 = 「**公众号 21:9 主封面 + 1:1 方封面成对编排**」→ 拆成 4 步：

1. **定长标题**（21:9）——写 1 行、≤14 字的长标题（`title-shortener.md` 的跨平台带宽表）。
2. **派生短标题**（1:1）——用 `title-shortener.md` **五步法**从长标题推 4-10 字短标题（**不许把长标题硬塞进方形**）。
3. **同一 HTML 内各自编排**——两图**各自构图**（`platform-specs.md`：21:9 标题在左安全区 + 右侧系统块；1:1 大字号居中、无图无副标题），加 `.pair-*` 配对预览同框。
4. **出图 + 核验**——Chrome headless 出 **2100×900 / 1080×1080 / 配对预览**，另导出**微信上传位 900×383**；插桩核验溢出/触边/标题字重。
