## 7. 坑（汇总，详见两阶段记录）
1. **Windows/MSYS 路径**：Chrome `--screenshot` 与 Python 读文件都要 Windows 路径。
2. **"裁一刀"诱惑**：skill 明令禁止把 21:9 裁成 1:1 → 必须单独派生短标题、独立构图。
3. **21:9 标题宽度贴线**：156px 下左栏标题实测铺满（961px），插桩确认未溢出、2 行。
4. **Python 中文路径**：`py 脚本.py` 找不到用户级 site-packages → 用 `py -c "exec(...)"`。
5. **磁盘**：Chrome 临时 profile 放 D 盘、用完即删。
