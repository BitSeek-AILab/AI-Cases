把模糊需求丢给 AI，得到的是“AI 味”模板页

不是你不会用 AI，是三件事没说清——这三件事，正是五步法要逼你交代的。

A

不知道怎么说

只丢一句“帮我做个网页”，AI 只能靠猜。类型没说清，骨架就定了型。

B

不知道该给什么

没有文案、图片、模块顺序，页面只能是个空壳，内容真实度无从谈起。

C

不知道改哪

一版出来全不对，一次改十处，越改越乱。得一轮只改一类问题。

五步 · 按顺序
  1. 01 定目标
  2. 02 给内容
  3. 03 给参考
  4. 04 生成第一版
  5. 05 逐项修改

五步怎么走

把需求拆成五步，Codex 更容易做准。

01

定目标

谁看、看完后要做什么动作。

交代：谁看 / 看完后要做什么动作
02

给内容

标题、文案、图片、Logo、模块顺序。

交代：这五样
03

给参考

说清喜欢的是布局、颜色、字体还是动效。

交代：从这四样里点名
04

生成第一版

先要能打开、能看、结构完整的版本。

交代：先别追求完美
05

逐项修改

一次只改一类问题：内容、布局、交互、移动端。

交代：一轮只动一类

怎么下手：三种起点

做网页不只有“从零写提示词”这一条路。以下三条为原文方法的意译整理（原文见《Codex 网页制作入门》P11）。

① 纯提示词

直接从一句需求写起，不依赖任何现成素材。

适合：需求简单、无品牌限制

② 参考链接

已看到喜欢的效果，让 Codex 拆它的布局 / 字体 / 颜色 / 动效。

适合：有明确想学的对象

③ 代码素材

有官方示例 / 开源组件 / CodePen demo，确认授权后改造。

适合：想站在别人肩膀上

直接抄的提示词模板

四项信息各有作用：类型定骨架 / 内容定真实度 / 参考定视觉交互方向 / 交付定代码结构。

交付前只看六件事

把“做完了”改成“验收通过”——AI 说做完了不算，这六条过了才算。

注：原文标题写“只看五件事”，实际列出 6 条——本页如实呈现 6 条。

  1. 01内容真实

    没有占位文案、假链接、空图片。

  2. 02手机可读

    390 宽不横向滚动，字号可读、按钮可点。

  3. 03交互完整

    能点、能切、有反馈——用户知道“可以做、做完了、出错了”。

  4. 04风格统一

    单一锚点色、一致的字体与网格、直角无渐变。

  5. 05授权清楚

    借方法不搬运：不用他人商标、图片、整站代码。

  6. 06能打开

    单文件、无外部依赖，离线双击即可打开。

参考站：看真实网站，别只看截图

六个高频参考来源（出处 P13）。不要只截图，要告诉 Codex 参考哪里：结构 / 视觉 / 交互 / 改成自己的。借方法，不搬运文案、商标、图片和整站代码。
