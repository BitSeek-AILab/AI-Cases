# 讲课大纲 · 案例编程-01 ｜ Codex 五步法做出第一版网页

> 手册只有"主题"（M4 P10 五步法），本大纲把**主题展开成一条可讲的线**。
> 讲法定位：**先给痛，再给法，再当场走一遍**——让学员看见"同一件事，说清楚 vs 说不清"的差别。

---

## 一、这节课要让学员带走什么（一句话）

不是"学会 HTML/CSS/JS"，而是**学会把一句模糊需求，拆成 AI 能执行的'目标 / 内容 / 参考'三件事**，
从而拿到一版**能打开的**网页。

## 二、开场（3 分钟）：先让学员"疼一下"

- **提问**：「你让 AI 做过网页吗？结果是不是——很好看，但一看就是模板，不敢发给别人？」
- **点破**（对应 M4 开场页）：`少一点名词堆叠，多一点能直接用的判断。`
- **给出对照**：同一句"帮我做个个人主页"丢给 AI，得到的是"AI 味模板页"；
  而先交代清楚"谁看 / 看完做什么 / 有什么内容 / 喜欢什么参考"，得到的是"能发出去的作品"。
- **落点**（M5 P03）：`作品比简历更快说话。先做出一个能被别人打开的东西。`

## 三、主体（25 分钟）：五步法，一步步讲 + 当场示范

> 讲法：**每一步都讲"不这么做会怎样 → 这么做要交代什么 → 一句话例子"**，并在本案例的真实产物里指出对应位置。

| 步 | 讲什么 | 一句话例子 |
|---|---|---|
| **01 定目标** | 谁看、看完后要做什么**动作** | "给想做网页的零基础的人看，看完要他们**照着五步走一遍**" |
| **02 给内容** | 标题、文案、图片、Logo、**模块顺序** | "首屏 + 5 个模块：问题 / 五步 / 上手 / 自检 / 参考" |
| **03 给参考** | 说清喜欢的是**布局 / 颜色 / 字体 / 动效** 里的哪一个 | "参考瑞士风：单一高亮色 + 网格 + 直角，不要渐变" |
| **04 生成第一版** | 先要**能打开、能看、结构完整**——不许一步到位 | 第一版允许粗糙，但要能双击打开 |
| **05 逐项修改** | **一次只改一类问题**：内容 / 布局 / 交互 / 移动端 | 第一轮只改文案，别顺手改布局 |

- **关键提醒 1**（M4 P11 三种起点）：做网页**不只有"从零写提示词"**——
  ① 纯提示词 ② 参考链接 ③ 代码素材（**确认授权后**改造）。
- **关键提醒 2**（M4 P12 提示词模板）：可直接抄的模板，四项信息各有作用——
  **类型定骨架 / 内容定真实度 / 参考定视觉交互方向 / 交付定代码结构**。
- **关键提醒 3**（M4 P14）：参考**不要只截图**，要告诉 AI 参考**哪里**（结构 / 视觉 / 交互），
  并且 **改成自己的**——"**借方法，不搬运**文案、商标、图片和整站代码"。

## 四、收尾（5 分钟）：交付前只看六件事（M4 P15）

> 六条自检：① 内容真实 ② 手机可读 ③ 交互完整 ④ 风格统一 ⑤ 授权清楚 ⑥ 能打开。
> 讲法：**把"做完了"改成"验收通过"**——AI 说做完了不算，这六条过了才算。

## 五、本案例的"当场示范"（这就是复刻要跑的东西）

现场用五步法，做一个**真实题材**：**"Codex 五步法"这套方法本身的落地页**。
- 为什么选它：**每句话都能在 M4 原文里找到出处**（五步、三种起点、模板、自检、参考站），
  天然能演示"内容真实（无占位文案/假链接/空图片）"这条红线。
- 学员看到的结果：一个**单文件、能双击打开、手机也能看**的落地页。
- 复盘时对着产物讲：**"你看到的这一版，就是五步一步步逼出来的"**。

## 七、给学员的课后动作（对应 M5 的"作业"精神）

1. 换一个**自己的**题材（摄影师 / 咖啡师 / freelancer / 小店…），**照五步走一遍**，做出第一版。
2. 交付前**逐条过六条自检**，把不通过的项写下来。
3. 把这次的五步交代**存成模板**，下次直接复用（别每次从头教 AI）。
