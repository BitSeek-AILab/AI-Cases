## 7. 踩到的坑（含"工装自己量错"的诚实记录）

1. **390 溢出（真问题）**：窄屏 `.steps-layout{grid-template-columns:1fr}` 的 `1fr` = `minmax(auto,1fr)`，
   而轨道 `ol` 是 `nowrap` 横向 flex → min-content 撑到 401px，把**整页**撑到 433px。
   → 改 `minmax(0,1fr)` + `min-width:0`。**教训：grid 里放可横滚/nowrap 的内容，一律 `minmax(0,1fr)`。**
2. **滚动高亮跳档（真问题）**：`IntersectionObserver` + `rootMargin` 的"带式"判据对短区块会错位。
   → 改"**视口中线判定**"（矩形是否跨过 `innerHeight*0.5`），稳定确定。
3. **"含渐变"误判（风格）**：点阵用 `radial-gradient` → 被风格核验判"含渐变"（瑞士风禁渐变）。
   → 换成 **SVG data-URI 点阵**，页面零 CSS 渐变。
4. **工装量错了（度量修正，已诚实记录）**：① 滚动定位用 `offsetTop+0.35h` 对短区块会落到下一块；
   ② 溢出判据把 `pre{overflow:auto}` **内部**长行也算页面横滚。→ 修正判据后**真问题仍被抓出**（没靠放松判据蒙混）。
5. **中文控制台乱码（环境）**：Git Bash 控制台 GBK，Node/Python 直接 print 中文会 mojibake。
   → 核验脚本一律**写 UTF-8 文件**，用 Read 工具读（与 `运行日志.md` 里既往案例同一处理）。
6. **文件编辑的精确匹配**：改 HTML 时 `Edit` 的 `old_string` 多次因**空格/换行差异**匹配失败
   （如 `slice(0,8)` vs `slice(0, 8)`）→ 用更长的上下文块或核对原文再改。
