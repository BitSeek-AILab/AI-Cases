## 三、内容约束（手册提示词 + 备课素材共同约束）

**手册提示词 5 条硬要求**：①题型丰富（直接计算/填空/判断/选择/应用题都要有）②每种题型3-5道 ③附答案和解析 ④排版整齐美观、A4打印刚好2页 ⑤生成Word文档

**手册成品页序（第03章 WorkBuddy 回复原文，逐字照抄）**：

> "文档整体布局：
> - 第1页：标题 + 直接计算(4题)+ 填空(5题) + 判断(5题) + 选择(4题)
> - 第2页：解决问题(3题，每题带4行作答区)
> - 第3页：参考答案及解析"

**手册成品题型/分值表（第03章截图原文）**：

| 题型 | 题数 | 分值 | 考查重点 |
|---|---|---|---|
| 一、直接计算 | 4题 | 20分 | 同分母/异分母加减，通分与约分 |
| 二、填空 | 5题 | 20分 | 基本运算、最小公分母、约分概念 |
| 三、判断 | 5题 | 10分 | 算理与易错判断 |
| 四、选择 | 4题 | 20分 | 算理与估算 |
| 五、解决问题 | 3题 | 30分 | 分数加减解决实际问题 |
| **合计** | **21题** | **100分** | |

**知识点严格取自备课素材**（`输入素材/分数加减法_备课素材.docx`）：
- 例1：1/2 + 1/3 = 3/6 + 2/6 = 5/6
- 例2：3/4 − 1/6 = 9/12 − 2/12 = 7/12
- 例3（易错）：1/2 + 1/4 = 2/4 + 1/4 = 3/4（**不是** 1/3）
- 随堂练习：1/3+1/6=1/2 ； 2/5+3/10=7/10 ； 7/8−1/4=5/8 ； 5/6−2/3=1/6 ； 应用 1/4+1/3=7/12
- 口诀："**先通分，再计算，能约分的要约分**"
- 易错点三条：①通分找错公分母（不是最小公倍数）②忘约分 ③只通分母忘改分子

**分数渲染**：一律用**上下结构的真分数**（OMML 数学公式），不用斜杠 `1/2`——手册成品截图里的分数就是上下结构（`\frac{3}{5}-\frac{1}{3}=\frac{9}{15}-\frac{5}{15}=\frac{4}{15}`），这是"排版整齐美观"的实测标准。
