## 关键步骤（严格按手册案例 11 的执行效果逐句做实）

手册执行效果 = 「**识别原文逻辑结构，替换专业术语为口语化表达，添加 emoji 分隔符与话题标签**」→ 拆成 3 步：

1. **识别原文逻辑结构**——把周报的"指标骨架"拆开，标出哪一段是"读者会关心的内核"、哪一段是"内部汇报语言"（保留/删除/改写）。
2. **替换专业术语为口语化表达**——术语 → 人话；报告句式 → 聊天句式；**同时换视角**（从"我司指标"→"对读者有什么用"）。
3. **添加 emoji 分隔符与话题标签**——emoji 做视觉锚点、分层标签命中推荐。
4. **配图建议**（案例清单要求）——按 `guizang-social-card-skill` 的**品类路由**（职场类 → Swiss × IKB）+ 平台尺寸规范，给封面/内页 shot list，并**真实渲染 1 张封面**。
