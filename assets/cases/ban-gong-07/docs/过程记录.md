## 全流程踩到的坑（供后续案例复用）

### 坑 1 · 「归档前」目录树在移动后才生成 → 空的（本案例新踩，已修正）
- 初版在**移动完**才调 `build_tree(args.inp)` 生成"归档前"树 → 源目录已空，清单里"归档前"只剩空壳。
- 修正：移动**前**快照 `before_tree`，写清单时用它。复跑后"归档前"正确列出 17 个文件。

### 坑 2 · 同一目录不能有两个同名文件 → 用子目录制造冲突
- 想测"同名不覆盖"，但一个文件夹里放不下两个 `report.pdf`。
- 解法：加子目录 `旧下载/`，跨目录同名（真实 Downloads 常见）→ 归档到同一目录时触发加序号。

### 坑 3 · 中文模块名 / 中文文件名
- 脚本名 `归档下载夹.py` 被 `清点下载夹.py` import：Python 3 支持非 ASCII 模块名，`sys.path` 加脚本目录后可正常 `from 归档下载夹 import …`。
- shell 拼中文路径易乱码 → 一律 `py -3` 传绝对路径。

### 坑 4 · 修改日期要显式设置
- 新写文件的 mtime 默认是"现在" → 必须 `os.utime(path, (t, t))` 设定，否则跨月归档测不出来。

### 坑 5 · 沿用：`python` 分裂 + vision MCP 401
- `python`→MSYS2（装不了库），一律 `py -3`（`E:\miniconda3\python.exe`）。`mcp__agent-vision__analyze_image` 返回 401 → 预览核对用 PIL 渲染 PNG 后**直接 Read 目视**。

```bash
py -3 "_脚本/make_inputs.py"     # 1. 造 17 个文件的乱下载夹（含子目录/同名/无扩展名）
py -3 "_脚本/清点下载夹.py"       # 2. 递归扫 + 算类型/年-月 → 归档前清单 + 清点结果

```

输入不变 → 结果不变。
