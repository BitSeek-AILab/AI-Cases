# 爆文结构模板 · 小红书（AI 工具 × 职场效率赛道）

> **给谁用**：把前面 20 条选题**变成一篇能发的笔记**时，套这份模板。
> **怎么来的**：`redbook analyze-viral` 实抓 3 篇 Top 爆款的结构 + 154 条爆款标题句式归纳 + 外部方法论（`资料 M1/M2`）交叉印证。
> **一句话**：**标题决定"点不点"，钩子决定"看不看"，结构决定"藏不藏"，标签决定"推不推"。**

---

## 五段式总览

```
① 标题公式  →  决定点击率（CTR）
② 开头钩子  →  决定 3 秒留存
③ 分段结构  →  决定收藏率（本赛道最强信号，>100% 是常态）
④ 结尾转化  →  决定关注/评论/私信
⑤ 话题标签  →  决定推荐与搜索命中
```

## ① 标题公式（16-21 字，含 1 个钩子元素）

**证据**：3 篇单篇分析的 `titleLength` = **21 / 16 / 21**；实抓 Top 标题集中在 16-21 字。

**5 大填空公式**（来源 `资料 M2`，已被实抓数据验证）：

| 公式 | 填空式 | 真实爆款样例（实抓） |
|---|---|---|
| **① 数字 + 结果** | `[N] + [动作] + [可感知结果]` | `如何在4小时内完成8小时的工作`（97%）、`20分钟内，掌握ChatGPT Work 95%的用法!`（129%） |
| **② 痛点 + 解决方案** | `[烦恼场景] + ？+ [解法]` | `为什么你生成的文章总有AI味？`（100%）、`避免AI工具焦虑…按需研究，边学边淘汰`（76%） |
| **③ 身份标签 + 场景** | `[人群] + [场景] + [结果]` | `普通人也能吃上的AI红利💰附接单全流程拆解`（124%）、`1h丨WorkBuddy零基础全流程教学`（157%） |
| **④ 反差 + 悬念** | `别急/别 + [反常识动作]` | `🚨别急着学AI！先把GitHub玩明白再说！`（119%）、`为什么不要一句话让 AI 做网站`（148%） |
| **⑤ 时间 + 紧迫** | `[时间] + [上手/搞定]` | `3分钟干完3天活`（183%）、`10分钟剪完了我一个月的社媒视频`（109%） |

**标题高频词库**（实抓归纳）：`一图看懂｜` `才知道…` `N个/N分钟…` `为什么不要…` `手把手教你…` `X上疯传…` `…附…拆解` `…必备…` `零基础` `免费` `别再…了`。

**标题四不要**：不要超过 21 字、不要没有钩子词、不要抽象（"提升效率方法"= 死）、不要与你赛道无关的热词硬蹭。

## ② 开头钩子（前 2 行，决定 3 秒留存）

**证据**：`analyze-viral` 检出的 `hookPatterns` = **Identity Hook（身份钩子）** 为主，辅以 Emoji。

**4 种开头钩子（选 1 种，写 1-2 句）**：

| 钩子类型 | 句式 | 例（可直接改） |
|---|---|---|
| **身份代入** | "如果你是[人群]，[这个场景]你一定遇过——" | "如果你是刚入职的新人，第一次做汇报 PPT 一定手忙脚乱——" |
| **反常识/劝退** | "别再[常见动作]了！其实[真相]。" | "别再收藏一百个 AI 工具了！其实你常用的就 3 个。" |
| **结果前置** | "[时间] 前我也[困境]，直到[转折]。" | "上周我还手动拉了半天的表，直到用 AI 三步搞定。" |
| **提问/悬念** | "[问题]？答案可能和你想的相反。" | "AI 写的邮件为什么一眼假？问题出在一句指令。" |

**钩子纪律**：开头**禁止寒暄**（"大家好我是…"）、禁止铺背景。**第一句就是信息**。

## ③ 分段结构（决定收藏率——本赛道最强信号）

**证据**：单篇正文 `bodyLength` = **91 / 148 / 300 字**，`paragraphCount` = **1 / 2 / 5**；收藏率 **129%-157%**（工具型）。→ **本赛道"短正文 + 高收藏"是常态**：用户收藏的是"**要点**"，不是"长文"。

**选 1 种骨架**（来源 `资料 M1` 六大结构，本赛道集中在①②③）：

### 骨架 A · 干货类 Why-What-How（最稳，适合"怎么做"）
```
【Why 为什么要会】1 句，戳痛点
【What 是什么/差别在哪】2-3 句，给出关键认知
【How 怎么做】分步 1/2/3 —— 每步一行、前面加 emoji
```
> 实例对应：`AI 三步把销售表变成能交的图`

### 骨架 B · 清单类（最适合"一图看懂/N个"图文）
```
【需求引入】1 句
【清单罗列】① … ② … ③ …（每条一行）
【一句话总结价值】
```
> 实例对应：`一人公司必备的 3 个 AI"员工"`

### 骨架 C · 对比类（适合"选哪个/A vs B"）
```
【对比对象】A vs B
【逐维分析】维度1 / 维度2 / 维度3
【结论建议】什么人选 A、什么人选 B
```
> 实例对应：`才知道不同的AI竟然有不同的分工`

**排版纪律**（微信/小红书通用）：
- **每段 ≤3 行**，段间空行；
- **大量换行**（实抓 `lineBreakDensity` 最高 1.67，即"一句一换行"都不过分）；
- **emoji 做分隔**（🔥✅💡⚠️📍），不是装饰——每个 emoji = 一个视觉锚点；
- 关键数字/结论**单独成行**。

## ④ 结尾转化（决定关注/评论）

**证据**：3 篇单篇分析的 `hasCallToAction` **均为 false** —— 视频类爆款的 CTA 常在**口播/评论区**承接（`为什么不要一句话让 AI 做网站` 的评论区在晒作品）。→ **图文必须显式写 CTA；视频可把 CTA 放评论区置顶。**

**3 种结尾（选 1）**：

| 类型 | 句式 | 适用 |
|---|---|---|
| **收藏引导** | "怕用时找不到？先点♥️收藏，[场景]直接抄。" | 工具型（本赛道主力） |
| **评论互动** | "你现在用 AI 干哪件活最多？评论区聊聊👇" | 拉互动、涨推荐 |
| **关注钩子** | "做[人群]的 AI 专栏，关注我不迷路。" | 涨粉 |
| **轻转化** | "需要[模板/清单]的，评论区扣『1』。" | 接单/引流（有计划再做） |

**红线**：CTA **不要**喊"点赞关注走一波"式空话；**要绑定具体价值**（"收藏这份[清单]"）。

## 七、把一个选题套出来（示例：A4「AI 三步把销售表变成能交的图」）

> **标题**（公式① 数字+结果）：`别再手动拉表！AI 三步把销售表变成能交的图`（21 字）

> **开头**（钩子：反常识）：`每个月做汇报，最烦的不是写 PPT，是手动拉那一堆销售数据——别再手动拉表了，AI 三步能搞定。`

> **正文**（骨架 A）：
> ```
> 💡 为什么：手动拉表不只是慢，还容易错，错一个数整页图都要返工。
> 📍 关键：不用学 Excel 函数，把"表 + 你要什么图"说清楚就行。
> 🔥 怎么做：
> ① 把原始销售表丢给 AI，说"按月份汇总销售额"
> ② 再说"画一张折线图，标出最高点"
> ③ 导出图，直接贴进 PPT
> ```
> **结尾**：`怕下次又忘步骤？先♥️收藏，做汇报直接抄。`
> **标签**：`#AI办公 #效率神器 #打工人 #AI工具 #Excel #howto用好AI`

> **形式建议**：**视频**（全流程实录，吃时长）+ **同步一条图文**（同选题拆"三步清单版"）。
