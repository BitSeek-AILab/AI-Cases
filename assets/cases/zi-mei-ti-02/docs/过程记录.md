## 第 1 步 · 备弹药（写 skill 清单 + 审查配置）

- **做了什么**：核本机 skill 可用性 → 写 `skill清单.md`；**先写** `审查配置/reviewer-brief.md`。
- **关键核查结论**：
  - `redbook` —— **可用**（CLI v0.8.2，`whoami` 返回用户「天马有空」）。**坑**：SKILL 写"macOS 专用"，本机 Windows，实测走"已保存 cookie 文件"路径正常 → 记**已实测、非降级**。
  - `anysearch` —— **可用**（Node CLI，实测返回）。
  - `md2wechat` / `guizang-social-card-skill` / `gpt-image` —— **本案例不需要**（产物是纯 Markdown，不涉及排版/出图）。
- **和手册一致吗**：手册未列 skill 名，仅描述能力；本复刻按 `工具插件skill索引.md` 选型。

## 第 2 步 · 照做 · 找同类爆款（skill `redbook` search）

- **做了什么**：8 个赛道关键词 × `redbook search --sort popular --json`，**逐条 + 间隔 8s**。
- **得到什么**：8 份 JSON（各 20-22 条）→ 合并 `_merged_all.tsv`（172 条记录，154 条有标题）。
- **和案例清单一致吗**：一致（期望产出要求"参照同类爆款"）。

## 第 3 步 · 照做 · 深挖结构（skill `redbook` analyze-viral）

- **做了什么**：挑 3 篇 Top 笔记跑 `analyze-viral --comment-pages 1 --json`，**间隔 25s**。
- **得到什么**：3 份结构分析 JSON（钩子模式 / 正文分段 / 标签 / 收藏率 / 离群倍数）。
- **关键发现**：收藏率 129%-157%（工具型）；Identity Hook 为主；标签 7-10 个；爆款是离群值（81×-350×）。
- **坑②**：`analyze-viral` 的 URL **必须用 search 结果里的 `webUrl`（含新 xsec_token）**，旧 token 会返回 `{}`——本次严格遵守。

## 第 4 步 · 照做 · 补方法论（skill `anysearch`）

- **得到什么**：5 大标题公式（`资料 M2`）+ 六大结构公式（`资料 M1`）→ `raw/extract/`。
- **和手册一致吗**：手册未提，属**方法补全**（标在 `skill清单.md`）。
