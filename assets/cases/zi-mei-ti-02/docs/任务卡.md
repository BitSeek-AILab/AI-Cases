## 要解决什么（一句话）
工具门槛降了，但**"写什么能爆"和"爆文长什么样"没人教**；运营者卡在选题和结构，不在文笔——本案例用真实爆款数据反推出**一份能直接排期的 20 条选题清单**和**一份能直接套用的爆文结构模板**。

## 关键步骤（严格按手册/案例清单顺序）

1. **找同类爆款参考**（对应 skill `redbook`）——按赛道关键词检索真实爆款笔记，抓点赞/收藏/评论/收藏率，判类型（工具型/认知型/娱乐型）。
2. **深挖爆款结构**（对应 skill `redbook analyze-viral`）——对 Top 笔记做单篇爆款分析，抽出标题钩子模式、正文结构、话题标签用法。
3. **补方法论**（对应 skill `anysearch`）——检索并抽取"爆款标题公式 / 结构公式"方法论，与真实数据交叉印证。
4. **挖选题**——把爆款数据 × 人群/场景，落成 **20 条选题清单**。
5. **提结构**——把单篇爆款分析与方法论，落成 **爆文结构模板（五段式）**。

## 用到 skill（详见 `skill清单.md`）
- `redbook`（小红书 CLI：`search` 找同类爆款 + `analyze-viral` 深挖结构）—— **本机可用**（Node ≥22 + 已登录 cookie）
- `anysearch`（检索 + 抽取标题/结构方法论）—— **本机可用**（Node CLI）

## 验收点
- [ ] 20 条选题清单，**按人群/场景分类**，每条含"人群 + 场景 + 选题标题 + 需求依据"
- [ ] 选题**有真实网感**（参照真实爆款，非模板腔）
- [ ] 爆文结构模板**五段齐全**：标题公式 / 开头钩子 / 分段结构 / 结尾转化 / 话题标签
- [ ] 结构模板的每一条**能追到真实爆款证据**（台账里的笔记/数据）
- [ ] 检索数据**真实**（redbook 实抓，非编造）；引用方法论有出处
- [ ] 明确写出**"哪些必须人工做"**（如账号定位、观点取舍、最终发布）
