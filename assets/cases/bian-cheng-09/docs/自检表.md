## 五、已知限制（如实登记，非打回项）

1. **未做真机测试**：手机可读性是通过 CDP `Emulation.setDeviceMetricsOverride`（390×844 / 320×720, `mobile:true`）量出来的，**没有在真实手机上打开过**。
2. **中文复制文本是"合成"的，不是原文**：`promptZh` 只是用途摘要，本案例的"复制中文"是把摘要 + 通用要求 + 占位符 + 验收标准合成成一份完整指令。**这是刻意的设计**（见 `痛点卡.md` 第五节），但用户需要知道：它不等同于"作者写的中文原版"——**原始作者只提供了英文原文**。页面上"来源说明"区保留了每条的取材方向。
3. **搜索是子串匹配**，不是语义检索：搜"卡片"不会命中写"card"的条目。76 条量级下子串匹配够用；条数上千时应换索引方案。
4. **`file://` 下的复制依赖 `isSecureContext`**：本次实测 `file://` 下 Clipboard API 可用；不可用时走 `execCommand` 兜底，再不行会 toast 提示手动复制（三路降级已实现，本次实测到第一路）。
5. **`pre` 是等宽字体**：在 390px 下设为 12.5px（已注明是等宽可读下限）；再窄的屏（<360px）会显得挤，但 320px 实测仍不横滚、可读。
