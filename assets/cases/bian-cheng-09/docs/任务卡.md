## ⚠️ 注意（沿用本项目已踩过的坑）

案例清单备注写得明确：

> 「材料原页用 JS 动态渲染，**只剥 HTML 拿不到内容**（本项目已踩坑并解决，见 `运行日志.md`）。复刻时数据源直接用 `prompts_extracted.json`。」

阶段1 已复核这条：静态 HTML 里 `<article class="card">` 只出现 **1** 次（那是 JS 渲染的模板外壳），**静态剥标签拿不到任何一条提示词**。所以本案例**不做 HTML 剥取**，直接吃 `prompts_extracted.json`。

## 要解决什么（承接痛点卡）

把"**76 条提示词散在文档里，搜不到、筛不动、复制要拖鼠标**"
变成"**打开一个文件就能边打字边收敛、分类和标签叠着筛、每条中英分别一键复制**"。

具体四件事：
1. **76 条全渲染**——修掉原成品"静默藏掉 21 条"的问题。
2. **筛选分两层**——分类（单选）与标签（多选取交集）分开，且能叠加。
3. **中文那份是合成出来的完整指令**——不只是搬那段用途摘要。
4. **手机 390px 可读**——因为"发出去"的主要场景是别人用手机点开。

## 验收点（供自检与审查）

- [ ] **76 条齐全**：页面渲染条数 == 数据源条数，且**逐条比对标题**无缺漏、无重复（不能只看总数）。
- [ ] **搜索生效**：输关键词后命中数变化；结果逐条真的含该关键词；无命中时出空状态。
- [ ] **分类筛选生效**：3 个分类 + 全部，条数与数据源各分类条数一致。
- [ ] **标签叠加取交集**：4 个标签单选 + 两两组合，条数等于"同时含这两个标签"的真值。
- [ ] **中文可复制**：复制到的文本**逐字等于**页面里那段 pre 的全文。
- [ ] **英文可复制**：复制到的文本以「中文名 / 英文名」开头且包含英文全文。
- [ ] **中英是两份不同的东西**：两个按钮复制出的内容不相等。
- [ ] **折叠不影响复制**：正文默认折叠（`max-height` 裁切）时，复制出来的仍是全文。
- [ ] **真单文件**：0 个外部资源引用。
- [ ] **手机可读**：390px 不横滚；320px 兜得住；不靠 `overflow-x:hidden` 掩盖。
