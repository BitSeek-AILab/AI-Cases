## 怎么用

1. **双击打开**（Chrome / Edge 均可），无需联网、无需安装任何东西。
2. **搜** —— 输入框打关键词（`Three.js` / `shader` / 看板 / 验收标准…），边打边收敛；按 `/` 聚焦，`Esc` 清空。
3. **筛** —— 上面一排是**分类**（单选：全部 / 纯交互动态 / 参考复刻 / Skill 模板），下面一排是**标签**（可多选，取交集）；两层可以叠着用。
4. **复制** —— 每条卡片里中英两栏各有一个按钮：
   - **复制中文** → 一份**五段式完整指令**（用途 / 交互要做到 / 实现要求与降级 / 需替换的占位符 / 完成标准），粘进对话框就能用；
   - **Copy EN** → 英文原文 + 「中文名 / 英文名」标题行。
   - 正文默认折叠，**但复制永远给全文**，与展开/收起无关。
5. **批量** —— 工具栏的"复制当前结果 · 中文 / EN"把**当前筛选出来的**条目整包复制走。

## 边界与已知限制

- **"复制中文"是合成出来的，不是原作者写的中文原文**：原始素材只提供了英文原文（`promptEn`）与一段中文用途摘要（`promptZh`，中位仅 84 字符）。本案例把它合成成一份完整指令。页面上每条保留了"来源说明"，`输入素材/来源说明.md` 第「版权与授权说明」一节也写明了这一点。
- 搜索是**子串匹配**，不是语义检索：搜"卡片"不会命中写"card"的条目。76 条量级够用；上千条时应换索引方案。
- 手机可读性是用 **headless Chrome 的设备模拟**（390×844 / 320×720）量出来的，**未在真实手机上打开验证过**。
- 未拷贝原成品的品牌素材（PSCAD.CN logo）；底部 6 条格式要求为**改写**；9 条参考来源外链照引（引用来源 ≠ 搬运内容）。
