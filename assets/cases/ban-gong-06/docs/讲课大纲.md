# 讲课大纲 · 办公-06 批量简历信息提取成表格

> 手册本案例只有一句话提示词，没有展开讲法。本大纲按《子Agent执行规范》要求，把"案例如何展开"补出来（标注【补全】）。

---

## 一句话定位

**学员带走的能力：** 把"一批版式各异的简历"变成"一张口径统一、可直接比较的筛选汇总表"。
**不讲的东西：** 不讲 Excel 筛选排序、不讲怎么写正则抽日期。学员不需要会，也不该会。

---

## 开场（3 分钟）：先制造痛，再给答案

【补全】开场三选一，本案例用"现场还原"。

**做法：** 现场同时打开 `输入素材/` 里两份简历，让学员看见：
- 一份小节叫「教育**背景**」，另一份叫「教育**经历**」；
- 一份日期写 `2017.07-2020.06`，另一份写 `2016年9月—2019年6月`；
- 一份实习**混在工作经历里**，另一份**单列「实习经历」**。

**关键提问（停顿，等学员答）：**
> "招聘季一天 50 份，你要把'姓名/学历/工作年限'敲进一张汇总表。哪一步最烦、最容易错？"

引导学员自己说出：**算工作年限**——日期格式五花八门，还得判断实习算不算、空窗扣不扣。

**收口：** "一天 50 份，2 到 3 小时，招聘季天天如此。更糟的是——**每个人算法不一样**，同批候选人一个把实习算进去了、一个没算，表看起来一样，**其实没法比**。这就是今天要解决的问题。"

---

## 主体（20 分钟）：走一遍真实链路

### 第 1 步 · 一句提示词启动（1 分钟）

念手册原句：

> **分析这份简历，提取关键信息生成表格**

强调：**不需要**先教它"你要先找姓名、再看教育背景、再算年限"。一句话，Agent 自己拆步骤，最后交出**一张表**。

### 第 2 步 · 读简历、抽字段（5 分钟）：讲"版式不一样怎么办"

展示 Agent 不是"按固定位置取"，而是**按含义识别**：
- 「教育背景」和「教育经历」都认得；
- 学历从教育行里识别（本科/硕士）；
- 姓名、岗位、联系方式都在**基本信息区**，不管排成几行都能取。

**关键提问：**
> "如果 50 份简历里有 10 种版式呢？"

答：**认"含义"不认"位置"**——只要信息在，版式变来变去不影响。这正是"人一份份看"最累的地方。

### 第 3 步 · 算工作年限（7 分钟）：本案例最高价值的一段

**陷阱 A —— 实习算不算？**
> "王芳 2018.07–2018.12 有一段'实习记者'，这段要不要算进工作年限？"

答：**不算**。实习是实习，不是正式工作经历。**但简历里实习可能单列一节，也可能混在工作经历里带个「（实习）」小字**——不认出来就会多算。本案例里王芳混在工作节、赵宇航单列一节，**两种放法 Agent 都认出来了**。

**陷阱 B —— 空窗期扣不扣？**
> "陈静 2019.07 开始工作、2026.10 还在职，中间 2022.03–04 待业两个月。她的工作年限是几？"

学员可能答"2019.07 到 2026.10，7.3 年"。
**答案是 7.2 年**——因为中间那 2 个月**待业，不是工作**，要扣掉。

> **收口：** "按'最早开始~最近结束'整段算，人会偷懒；但**待业的时间不是工作年限**。差 0.1 年看着小，可要是空窗是半年、一年呢？年龄、资历全错。"

**这一段的板书金句：** "**工作年限 = 一段一段加起来，不是首尾一减。**"

### 第 4 步 · 汇总成表（4 分钟）：讲"口径统一才有可比性"

展示 `简历信息汇总表.xlsx`：5 行、13 列，**同一套口径**算出来的年限，**按年限降序**排。

**关键提问：**
> "为什么一定要统一口径？我就按大概估的行不行？"

答：**不行**。表的意义是**比较**——一个把实习算进去、一个没算，"谁更资深"的结论就是错的。**口径统一，是这张表能用来筛人的前提。** 所以本案例把口径写进了表格的「字段与口径说明」sheet，谁看都知道这张表是怎么算出来的。

### 第 5 步 · 留痕与核对（3 分钟）：讲"表要能倒查"

展示「来源文件」列与 `抽取结果.json`：每行都能追回是哪份简历，每个年限都能看到是哪几段经历加出来的。

**关键提问：**
> "用人部门问'刘洋这个 8.7 年怎么来的'，你怎么答？"

答：**照着片段清单答**——两段经历逐段时长清楚。**表不光要好看，还要经得起追问。**

## 收尾（7 分钟）：从"这一批"到"每一批"

### 对比表（板书/投屏）

| | 手工 | 本次链路 |
|---|---|---|
| 读简历 | 一份份打开找信息 | 批量读、按含义抽字段 |
| 抄表 | 逐字复制粘贴 | 自动汇总 |
| 算年限 | 自己加加减减、易错 | 逐段规范化 + 统一口径 |
| 实习/空窗 | 常常忘记判断 | 显式识别并排除 |
| 汇总上报 | 口径不一、不可比 | 一张口径统一的表 |
| **耗时（50 份）** | **2–3 小时** | **分钟级** |
| **下一批** | **再来一遍** | **换一批简历，重跑一次** |

### 收束提问（回扣痛点卡）

> "今天真正省下来的，是那 2–3 小时吗？"

引导到正确答案：**省下来的是"口径不一导致筛错人"的风险，和"招聘季天天还要再来一遍"。**

### 留给学员的一句话

> "你不需要会做候选人台账。你需要会**说清楚口径**，以及**看得懂这张表对不对**。"

---

## 板书/PPT 要点（备查）

1. 一个动作：读简历、按"含义"抽字段（版式变来变去不怕）
2. 一个口径：工作年限 = 各段正式工作逐段相加（含首尾月）
3. 两个排除：实习不算、空窗不算
4. 一个前提：口径统一，表才有可比性
5. 一条留痕：每行能回溯到源文件与经历片段
