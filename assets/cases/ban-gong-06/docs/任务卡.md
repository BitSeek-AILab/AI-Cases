## 工作年限口径（本案例的核心，必须统一）

```
段时长(月) = (止年×12 + 止月) − (起年×12 + 起月) + 1   （含首尾月）
工作年限(月) = 各段【正式工作】月数之和   ← 实习不计入、待业/空窗不计入
「至今」按 2026年10月 计
工作年限(年) = 月数 ÷ 12，保留 1 位小数
```

- 示例：陈静 2019.07–2022.02（32 月）+ 2022.05–至今（54 月）= **86 月 = 7.2 年**；中间的 2022.03–04 待业**不计入**。

## 验收点（自检表逐条对应）

1. 2 类交付物真实落盘、能打开（xlsx 可开、两个 sheet 齐全；json 可读）——**不许只描述不产出**
2. 5 份简历**全部**被处理，汇总表 5 行、**一行一人，不多不少**
3. 字段与手册一致：**姓名 / 学历 / 工作年限 / 关键经历** 四类必备字段齐全；学历识别正确（本科/硕士）
4. **工作年限口径统一且正确**：陈静 7.2（非 7.3）、王芳 7.3（非 7.8）、赵宇航 1.3（非 1.8）
5. **实习不计入**：王芳、赵宇航的实习被识别但**不进入**年限计算
6. **空窗不计入**：陈静的 2 个月待业被识别并**扣除**
7. 所有字段**由简历真实抽取**，无编造；`verify.py` 与标准答案逐字段比对通过
8. 按手册步骤顺序执行，未跳步、未擅自增加产物形态（不做 PPT / 不做打分排序算法）
9. 【替代】标注齐全（WorkBuddy「AI 分析简历」→ 读 docx + 规则抽取；导出 → xlsx skill）

## 明确的边界（不做的事）

- 不做"简历打分/自动排序推荐"（手册只要求"提取关键信息生成表格"，不要求判断谁好谁坏）
- 不做个人隐私字段的深度挖掘（只取简历里明写的联系信息，用于核对）
- 不引入手册未提及的能力（如 OCR 扫描件、自动发送邮件）
