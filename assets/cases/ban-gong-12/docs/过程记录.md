## 全流程踩到的坑（供后续案例复用）

### 坑 1 · 段落提取要按"章节状态机"，否则越界收纳
- 首版 `read_minutes.py` 用"贪心收正文段"把议题4 的正文一直收到文末，把"五、其他口头共识"的 2 条和"附：时间戳索引"整段也塞进了议题4。
- **结论：解析有分节标题的文档，必须用"章节状态机"（遇到分节标题即切换状态、清空当前挂点），不能靠"下一个议题标题"当边界。**

### 坑 2 · Python 字符串里的中文引号要小心
- `to_md` 里写了 `用于"不编造、不拔高"的核对`，其中引号是 **ASCII `"`** → 提前结束字符串，`SyntaxError: invalid character '、'`。
- **结论：中文文案里一律用全角引号「」/“”，别用 ASCII 引号，避免字符串截断。**

### 坑 3 · python-pptx 中文必须显式设 ea 字体
- 只设 `run.font.name` 只写 `<a:latin>`，中文字符在部分环境回退成宋体/方框。
- **解法：给每个 run 手动写 `<a:ea typeface="微软雅黑">` 与 `<a:cs>`。**

### 坑 4 · headless 渲染别把页面 UI 拍进去
- 网页版右下角有"1 / 12"页码提示 `#hint`，直接截图会入镜。
- **解法：渲染前 JS 设 `#hint.style.display='none'`。**

### 坑 5 · 禁用通道（沿用办公-01/02/03）
- `mcp__agent-vision__analyze_image` **返回 401** → 视觉核对走"Chrome headless 渲染页图 + **直接 Read 图**"；
- 一律用 `py -3`（`E:\miniconda3`）才有 python-docx / python-pptx；
- **不用 Word/PowerPoint COM 出图/出 PDF**（办公-02 实测被"文档恢复"面板阻塞）。

### 磁盘维护（环境限制备忘要求，已执行）
- 起 headless Chrome **前**先 `df -h /c` 看剩余（本次 1.9 GB）；
- 渲染脚本 `render_png.mjs` **结尾杀自己的 Chrome 进程 + 删自己的临时 profile（`%TEMP%\cdp-*`）**；
- 图片产物为 1280×720 @2x，**未全页高清堆叠**。

## 规模可扩展性说明

手册痛点场景为"10 页汇报从零搭 1-2 小时"。本案例的脚本**按 `汇报结构.json` 的页列表循环渲染**——议题更多、页数更多，只改循环次数，**"读纪要 → 提炼结构 → 成页"的方法不变**。这正是"会每周都开、每周都要重做一遍"痛点的真正解药：**换一份纪要文档，整条链路重跑一次即可**。
