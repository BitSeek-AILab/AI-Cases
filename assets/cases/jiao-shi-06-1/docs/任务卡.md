## 要解决什么（承接痛点卡）

把"对着空白 Word 发呆 1—2 小时"变成"先给框架、再展开细节、后按需打磨，半小时出可用稿"。
本班学情：**学生学过写景散文，但分析手法还弱**（停留在"写得美"的笼统感受，不能识别比喻/拟人，缺条理赏析）。

## 最终交付物清单

1. `阶段1_骨架/` —— 《春》第一课时教学框架（目标/重难点/流程时间段+学生产出），**不展开全文**。
2. `阶段2_血肉/` —— "导入"环节逐分钟脚本（老师说什么、学生做什么，3 分钟进入"春天"状态）。
3. `阶段3_打磨/` —— 练习环节改小组合作版 + 作业布置写具体（明确交什么）。
4. `最终产物/《春》第一课时教案.docx` —— 打磨后的**完整教案**，A4 可打印。
   - 含：教学目标、教学重难点、教学过程（导入→新授→练习→小结→作业，标注时间）、板书设计。
   - 含：针对"分析手法弱"的 **"手法+原句+效果"赏析支架**。
   - 含：**融入思政元素**（自然不生硬）。
5. 过程记录、审查配置、自检表。

## 验收点（供自检与审查）

- [ ] 严格按"骨架→血肉→打磨"三步顺序，每步单独落盘、不跳步。
- [ ] 骨架只给框架，不提前展开全文。
- [ ] 导入展开成逐分钟脚本，3 分钟能把学生带入"春天"状态。
- [ ] 练习改小组合作；作业写清"要交什么"。
- [ ] 产出真 `.docx`，A4 可打印，能被 Word 打开。
- [ ] 赏析支架可直接教给学生用。
- [ ] 思政自然融入，不生硬说教。
- [ ] 痛点被真实解决（空白→框架）。

## 红线

- 不许只描述不产出；`最终产物/` 必须有真能打开的 `.docx`。
- 手册说啥做啥，不擅自改顺序。
