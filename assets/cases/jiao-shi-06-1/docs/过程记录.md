## 遇到的坑（汇总）

1. **路径括号陷阱**：源目录名 `...教师版手册（5个文件夹)` 的左括号是全角 `（`、右括号是**半角 `)`**，与任务卡描述的"全角括号"不符。用 PowerShell 列目录定位后解决。
2. **Bash 工具中文路径乱码**：Git Bash 对含中文路径报 `No such file or directory`；改用 PowerShell / Glob 处理。
3. **`docx` 未全局可解析**：`require('docx')` 首跑失败（skill 说"preinstalled"，本机实际需装）；按 skill 指引在 `_build` 内 `npm install docx` 解决。
4. **本机无 LibreOffice / pandoc / python-docx**：docx skill 推荐的 `soffice.py` 渲染链不可用（【替代】）。改用 ① XML 解包校验 + ② Word COM 渲染 PDF + 计数页 + ③ `pdftoppm`（TeXLive 自带）出图目视三条路交叉验证，结论可靠。
5. **`pdftoppm` 该版不支持 `-jpeg`**：改用 `-png`；另有 `No display font for 'ArialUnicode'` 警告，不影响中文渲染。
6. **docx 段落边框键序**：板书区边框段落按 top→bottom→left→right 书写，docx-js 未报错，渲染正常（Word COM 验证通过）。
