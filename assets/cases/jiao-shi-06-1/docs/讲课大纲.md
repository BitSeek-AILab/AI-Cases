## 四、手册已给的锚点（照着对齐，不另起炉灶）

1. **赏析支架**：手册 WorkBuddy 回复原文——"针对'学过写景散文但分析手法弱'这一学情，核心策略是搭一个赏析公式支架**手法 + 原句 + 效果**，先师生共析建立模型，再让学生迁移运用。"
2. **时间分配（骨架表）**：导入 3′ / 新授1 初读正音 5′ / 新授2 整体感知 7′ / 新授3 精读赏析 10′ / 练习（迁移）8′ / 小结 2′。（合计 35′，另有课堂小测/作业段）
3. **另一版骨架（正式教案页）**：导入 3′ / 新授1 作家与朗读 7′ / 新授2 精讲赏析 15′ / 练习 8′ / 小结 4′，并列有"信息技术融合"列。
4. **导入逐分钟脚本**：第1分钟 情境入春（听，鸟鸣+溪流声）→ 第2分钟 诗句接龙（说）→ 第3分钟 揭题蓄势（读，"盼望着")。
5. **小结口诀**：一线索、五画面、两手法、一方法。
6. **作业/小测**：备课碎片要求"最后3分钟做课堂小测"。
