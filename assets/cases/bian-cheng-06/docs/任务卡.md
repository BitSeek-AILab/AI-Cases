## 要解决什么（承接痛点卡）

把"**要花 40-60 分钟从 3 个来源拼 Excel 才能看一眼，改个口径还得求人排期**"
变成"**双击一个文件，一眼看到关键数字与趋势，并且自己就能改口径**"。

具体五件事：
1. **一眼就是答案**——hero 大数字（本期净销售额）+ 6 个 KPI 磁贴，每个都带"较上期"方向与幅度。
2. **看得见趋势**——本期 vs 上期双折线（30/14/7 天），带十字准线 + 读数 tooltip。
3. **看得出结构**——渠道 GMV 横条（单色系，量级比较）+ 品类占比 100% 堆叠条（分类配色 + 图例）。
4. **下钻得到明细**——40 个 SKU 的明细表，**点表头排序 + 品类 chip 筛选 + 渠道下拉 + 搜索**，并显示"显示 N / 共 M"。
5. **改口径不求人**——时间范围预设（近 7 / 14 / 30 天）**一处切换、全页重算**（KPI、3 张图、明细表同步）。

## 验收点（供自检与审查）

**A. 图表渲染（红线）**
- [ ] **A1 三张图都真渲染**：SVG 路径非空、坐标是有限数（无 `NaN`/`Infinity`）、所有几何点落在 viewBox 内、每个数据点都有对应的 mark（数量与切片数据条数一致）。
- [ ] **A2 折线是"本期 vs 上期"两条**，且**共有图例**、**端点有 2px 面色描边环**、**不给每个点标数**。
- [ ] **A3 渠道条是单色系**（不是按数值深浅的彩虹/色阶 —— dataviz 反模式"nominal 类别上套数值色阶"），值标在条端。
- [ ] **A4 品类占比是 100% 堆叠条**，段间有 **2px 面色间隙**（不是描边），有图例，段内标签放不下就不放（不裁剪）。
- [ ] **A5 无双 Y 轴**、网格线为**实线发丝线**（非虚线）。
- [ ] **A6 悬停层可用**：折线有十字准线 + 一次列出该 X 上全部系列的 tooltip；条形/堆叠段各自有 hover tooltip 且被 hover 的 mark 有可见响应；**键盘 focus 得到同样的读数**。

**B. 筛选 / 排序交互（红线）**
- [ ] **B1 时间范围**：近 7 / 14 / 30 天切换后，**全页数字同步重算**（KPI、3 图、明细表），且与**独立算出的真值一致**（不是只换了标签）。
- [ ] **B2 表头排序**：点任意列，升/降序切换生效，且**排序结果与独立排序一致**（抽查 3 列 × 2 方向）；排序有可见的方向指示。
- [ ] **B3 品类筛选**：chip 单选生效，表格行数与真值一致，出现"显示 N / 共 M"计数。
- [ ] **B4 渠道筛选**：下拉生效，与品类筛选**可叠加**。
- [ ] **B5 搜索**：输入子串（商品名/SKU）即时收敛；**无命中时出空状态**（而不是空白表格）。
- [ ] **B6 数字口径自洽**：hero = 本期净销售额；KPI 的"较上期"方向与独立算出的差值同号；分发到 3 张图的量级互相不矛盾（渠道合计 = 品类合计 = 本期总 GMV）。

**C. 手机可读不横滚（红线）**
- [ ] **C1 390px**：`window.innerWidth === 390` **且** 摘掉 `html/body` 的 `overflow-x:hidden` 之后 `document.documentElement.scrollWidth ≤ 390`（**只看隐藏状态下的 scrollWidth 一律无效**）。
- [ ] **C2 320px** 同样兜得住。
- [ ] **C3 明细表窄屏**：不靠"表格整体横向滚动条"糊过去 —— 窄屏下将低优先列收纳或改为卡片式行，**关键列（商品名 / GMV / 环比）必须在首屏可见**。
- [ ] **C4 交互在窄屏仍可点**：时间范围预设、品类 chip、排序按钮的命中区 ≥ 32px 高。

**D. 内容真实 / 风格统一 / 授权清楚 / 能打开**
- [ ] **D1 数据自造但合理**：无负数/无 NaN；GMV、订单、UV、退款之间的推导关系自洽（客单价 = GMV/订单、转化率 = 订单/UV、退款率 = 退款/GMV）；周末与国庆（10-01~10-03）有可见的季节性抬升。
- [ ] **D2 演示数据在页面内 JS 生成**，**零外链**（`link[href]`/`script[src]`/`img[src]` 非 `data:` 的资源引用为空数组）；且**与 Python 参考实现的逐行哈希一致**。
- [ ] **D3 风格统一**：配色只用 `dataviz` 已验证调色板里的槽位与 ink token；文字不穿数据色（数值/标签用 ink token，识别靠旁边的色块/线键）。
- [ ] **D4 能打开**：`file://` 双击可开，离线可用；深浅两套主题都可读。
- [ ] **D5 授权清楚**：不含任何品牌 logo / 受版权素材 / 外部字体；商品名与数据均为虚构（并在页脚注明）。

## 红线

- 不许只描述不产出：`最终产物/` 必须有真能双击打开的 HTML。
- 必须做**功能 + 视觉核验**：headless Chrome 打开、截图、实测时间范围/排序/筛选/搜索/tooltip/手机宽度。
- 手机 390px 必须真不横滚，**判据不能只看 `scrollWidth`**（移动端 shrink-to-fit 会骗人；`overflow-x:hidden` 会把溢出藏起来）。
- 图表必须**真渲染**（几何点有限、在框内），不能只有 SVG 空壳。
- 数据自造但必须合理；**页面数据必须与 Python 参考实现逐行一致**（哈希比对），不许"看起来像"。
- 截图存证，过程记录逐步写。
- 借方法不抄袭：不引入第三方图表库或模板代码；视觉为原创方向。
