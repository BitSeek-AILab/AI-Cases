## 四、自己发现并修正的问题（诚实记录）

| # | 问题 | 修正 |
|---|---|---|
| 1 | `md_to_docx()` 让 markdown 粗体标记 `**` **漏进 docx 列表项**（预览图出现字面 `**5 份**`） | 转换前整行 `clean = s.replace("**","")`，各分支统一用 `clean`；复跑后 docx/PDF 无字面 `**`（PDF 字符数 1040→992） |
| 2 | `⚠` 在本文档字体下渲染为 `△`（字形替换，非缺字） | 警示符换成 `▲`（U+25B2，通用性更好） |
| 3 | 成员初按文件名顺序排列（李四/孙八/张三…），不符报告阅读习惯 | `list_and_plan.py` 改为按**团队名单顺序**排序（张三→李四→王五→钱七→孙八） |
| 4 | `汇总周报.py` 每次运行向 `转换日志.txt` **追加**，多次试跑后出现重复条目 | 定稿前删除旧日志重跑一次，日志只保留最终一次的记录 |
