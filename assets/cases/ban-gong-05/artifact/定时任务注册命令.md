# 定时任务注册命令（演示 · 命令已给出，**本机未实际注册**）

> 手册原句：**「每天9点自动汇总D盘「周报」文件夹内Word文档……」**「设置定时任务，每天自动执行文件汇总、转换和发送。」
> 本文件把"每天 9 点"这句抽象需求，落成**一条可复现的 Windows 计划任务命令**。
>
> ⚠️ **重要声明：本机未实际注册该计划任务。** 注册（`schtasks /Create`）会**修改本机系统状态**（写入任务计划库、可能弹 UAC），超出"复刻演示"的红线，故本案例**只输出命令 + 逐字解释 + 卸载命令**，不执行注册。
> 你在自己电脑上，把下面第 1 条命令**粘进"以管理员身份运行的 CMD/PowerShell"，回车一次**就完成了注册——这一步没有技术含量，只是需要一次管理员授权。

## 一、前置：定时任务调用的入口

计划任务不直接指向 `.py`，而是指向批处理入口（内部调 Miniconda Python，因为本机 `python` 指向 MSYS2，装不了科学计算库）：

```
D:\...\案例办公-05_定时周报汇总\_脚本\run_daily_summary.bat
```

（本机实际绝对路径：`D:\CAREER\AI第二期\课程产品矩阵\AI沙龙-10月\横刀实战\进一步复刻_工程\复刻产出\办公\案例办公-05_定时周报汇总\_脚本\run_daily_summary.bat`）

## 二、注册命令（每天 09:00）

在**以管理员身份运行**的命令行里执行：

```cmd
schtasks /Create /TN "WorkBuddy_团队周报汇总" /TR "\"D:\CAREER\AI第二期\课程产品矩阵\AI沙龙-10月\横刀实战\进一步复刻_工程\复刻产出\办公\案例办公-05_定时周报汇总\_脚本\run_daily_summary.bat\"" /SC DAILY /ST 09:00 /RL HIGHEST /F
```

### 逐字解释

| 片段 | 含义 |
|---|---|
| `schtasks /Create` | 创建计划任务（Windows 自带，无需装任何东西） |
| `/TN "WorkBuddy_团队周报汇总"` | 任务名（Task Name），自定义；用于查询/删除时定位 |
| `/TR "\"...run_daily_summary.bat\""` | 要执行的命令（Task Run）。**整个路径要用成对双引号包住**，因为路径含中文/空格；外层再套一层转义引号 |
| `/SC DAILY` | 触发频率 = 每天（Schedule） |
| `/ST 09:00` | 触发时间 = 09:00（Start Time），对应手册的"每天9点" |
| `/RL HIGHEST` | 以最高权限运行（Run Level），避免读写文件/弹窗被拦 |
| `/F` | 同名任务已存在则覆盖（Force） |

> **与手册的对应：** "每天9点" → `/SC DAILY /ST 09:00`；"自动汇总…转换和发送" → `/TR` 指向的入口批处理里跑完 汇总→转PDF→命名 全链路。

## 三、配套命令（验证 / 手动跑 / 卸载）

```cmd
rem ① 查看任务是否注册成功、下次运行时间
schtasks /Query /TN "WorkBuddy_团队周报汇总" /V /FO LIST

rem ② 不等 9 点，立刻手动跑一次（首次配置后建议先这样验证）
schtasks /Run /TN "WorkBuddy_团队周报汇总"

rem ③ 撤销：删除该计划任务（不再每天自动跑）
schtasks /Delete /TN "WorkBuddy_团队周报汇总" /F
```

**幂等性说明：** 入口脚本每次**重新生成**汇总（不往旧文件里追加），所以重复触发不会造成内容重复累加；同名产物被覆盖为最新一次结果。这正是"定时任务可以放心每天跑"的前提。
