| 项 | 内容 |
|---|---|
| 做了什么 | 按日期把 56 行切成"上周 28 / 前一周 28"，算大区与门店的销售额/订单/客单价与环比 |
| 调了哪个 skill | `xlsx` 规范；【替代】WorkBuddy 自动取数 → openpyxl + 脚本 |

**结构效应判定：** 四家店客单价两周都没变（380/320/290/200），大区客单价却从 313.65 降到 311.56 → 纯由松山湖（低客单价店）占比从 10.27% 升到 11.88% 造成。报告显式标注"不能据此判断客单价在下降"。

## 全流程踩到的坑（供后续案例复用）

### 坑 1 · openpyxl 读到的日期是 `datetime`，不是 `date`（本案例新踩）
- `isinstance(d, date)` 对 `datetime` **也返回 True**（datetime 是 date 的子类），于是没走转换分支，切周比较时抛
  `TypeError: can't compare datetime.datetime to datetime.date`。
- **结论：读 xlsx 日期列时先判 `isinstance(d, datetime)` 再取 `.date()`。**

### 坑 2 · Markdown 星号在 Word 里不渲染
- 报告文案里写 `**不能**`，python-docx 按原样落进 docx，PDF 上直接露出 `**不能**`。
- **结论：docx 里要用加粗就设 run 的 `bold=True`，不要写 Markdown 标记。**

### 坑 3 · 没有 LibreOffice，xlsx 的 recalc.py 不可用
- 改用 Excel COM（`CalculateFullRebuild`）。**没查清就照抄 skill 命令会白跑一轮。**

### 坑 4 · Word COM 导 PDF 的两种方式，一种出来读不了
- `SaveAs(FileFormat=17)` 导出的 PDF，读取器报 "password-protected"；改用 `ExportAsFixedFormat` 正常。

### 坑 5 · 本机 Python 分裂成两个
- `python` → MSYS2 mingw64（装不了科学计算包）；`py -3` → `E:\miniconda3\python.exe`（openpyxl/matplotlib/python-docx/pywin32/pymupdf 都在）。
- **结论：本机一律用 `py -3`。**

### 坑 6 · `%` 格式化不支持 `%,d`
- `print("...%,d..." % x)` 抛 `ValueError: unsupported format character ','`。改用 `format(x, ",")`。

### 坑 7 · 视觉核对通道不通，需备替代
- `mcp__agent-vision__analyze_image` 返回 **401**。替代：图表 PNG 直接 Read 看；PDF 用 `pymupdf` 渲染页面 PNG 逐页目视。

### 坑 8 · Word/Excel COM 会残留僵尸进程（本案例导出 PDF 时留下）
- 本案例第 6 步用 Word COM `ExportAsFixedFormat` 导 PDF，**导出成功了**，但 `word.Quit()` **没把 WINWORD 进程彻底退掉**，留下一个不可见进程。
- 后果：**下一个案例（办公-02）再用 Word COM 时，`DispatchEx` 报 `0x80080005`、`Documents.Open` 直接挂起**；强杀该进程后又触发 Word"文档恢复"面板，把 COM 彻底堵死（详见 办公-02 过程记录 坑1/坑2）。
- **结论：Office COM 用完必须确认进程真的退出**（`Quit()` + 释放引用 + `CoUninitialize()`），后续案例才能安全复用 COM。本案例脚本已按此加固。

## 复跑方式（可重复验证）

```bash
py -3 "_脚本/make_inputs.py"                                                # 1. 生成输入素材
py -3 "_脚本/analyze_and_summary.py"                                        # 2. 切周 + 汇总 + 环比 → xlsx + 核对数据
py -3 "_脚本/com_utils.py" recalc "阶段1_读数据与环比核对/上周销售汇总.xlsx"   # 3. 公式重算
py -3 "_脚本/make_charts.py"                                                # 4. 出 3 张图
py -3 "_脚本/make_report.py"                                                # 5. 出 docx 日报
py -3 "_脚本/com_utils.py" topdf "最终产物/上周销售日报.docx" "最终产物/上周销售日报.pdf"  # 6. 导 PDF
py -3 "_脚本/verify.py"                                                     # 7. 回读核对 + 渲染 PDF 页面
```

输入不变 → 结果不变。（图表与报告都读 `阶段1/汇总核对数据.json`，不重算。）

## 规模可扩展性说明

手册场景为"从本地 Excel 或企业微信表格提取数据"，真实情况可能涉及多个门店/多张表。**本案例脚本按日期切周（不依赖文件数），把源表换成"多份流水合并后的表"或"更长周期"都能直接跑** —— 加表/加周期不改逻辑，这正是"每周重来"痛点真正的解药所在。
