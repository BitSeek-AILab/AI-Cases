# 讲课大纲 · 办公-01 销售日报自动生成

> 手册本案例只有一句话提示词，没有展开讲法。本大纲按《子Agent执行规范》要求，把"案例如何展开"补出来（标注【补全】）。

---

## 一句话定位

**学员带走的能力：** 把"一张混着好几周的销售流水表"变成"一份周一一早就能发群的销售日报"。
**不讲的东西：** 不讲 SUMIF、不讲环比公式怎么设、不讲 matplotlib 语法。学员不需要会，也不该会。

---

## 开场（3 分钟）：先制造痛，再给答案

【补全】开场三选一，本案例用"现场还原"。

**做法：** 现场打开 `输入素材/华南大区销售流水_20260928-20261011.xlsx`，让学员看见**两周 56 行数据混在一张表里**，
- 日期列从 09-28 一直排到 10-11，跨了两周；
- 表里**没有**客单价，只有销售额和订单数；
- **没有**任何"这是第几周"的标记。

**关键提问（停顿，等学员答）：**
> "周一早上 8:30 要发上周日报，你从这张表里要做的第一件事是什么？做错会怎样？"

引导学员自己说出：**先得把"上周那 7 天"框出来**——框错一行，整份日报的周期就错了，而且发出去看不出错。

**收口：** "手工做，30 到 40 分钟；每周一重来一次。更麻烦的是，框错周、环比符号写反、模板日期没改——**日报看起来完全正常，但数字是错的，而且已经发到群里了**。这就是今天要解决的问题。"

---

## 主体（20 分钟）：走一遍真实链路

### 第 1 步 · 一句提示词启动（1 分钟）

念手册原句：

> **生成上周销售日报**

强调：**不需要**先说"你要先取数、再算环比、再套模板、再导 PDF"。一句话，Agent 自己拆步骤，最后交出**能发群的 PDF**。

### 第 2 步 · 取数与切周（5 分钟）：讲"Agent 怎么不框错周"

展示 Agent 不是靠肉眼框选，而是**按日期自动切分**：
- 把 10-05~10-11 归为"上周"，09-28~10-04 归为"前一周"；
- 两段各 28 行（4 店 × 7 天），合起来 56 行 = 源表全部。

**关键提问：**
> "如果源表里混了三周、五周呢？"

引导学员理解：**只要告诉它'上周'是哪几天，它就会去切；表里混多少周都不影响。** 这跟"人工框选"是两回事——人越框越慌，Agent 越混越稳。

**现场核对：** 数一数两段行数——**28 + 28 = 56**，不多不漏。

### 第 3 步 · 算汇总与环比（6 分钟）：埋两个"专业陷阱"

这一段的重点不是公式，是**两个最容易错的口径**。

**陷阱 A —— 环比符号：**
> "天河店上周做了 205,900，前一周 234,320，环比是多少？"

学员答 `(205900−234320)/234320 = −12.13%`。**重点不是数字，是那个负号。** 四家店里天河是**唯一下降**的，另外三家都在涨（福田 +2.88% / 南山 +12.65% / 松山湖 +20.33%）。**手工算环比时，减反方向、漏掉负号是最常见的错，而且报表不会报错。**

**陷阱 B —— 客单价口径（本案例最高价值的一问）：**
> "四家店的客单价分别是 380、320、290、200，那么大区的综合客单价是多少？"

学员大概率会答 `(380+320+290+200)/4 = 297.50`。
**答案是 311.56**，因为正确算法是 `大区销售额 ÷ 大区订单数 = 1,116,320 ÷ 3,583`。**差 14 元。**

> **收口（第二层，更阴险）：** "上周大区客单价 311.56，前一周 313.65，跌了 0.67%。那是说客单价在降吗？"
> **不是。** 四家店**各自的客单价一点没变**（380/320/290/200）。跌，是因为**低客单价的松山湖店卖得特别猛（+20.33%），把整体结构拉低了**。这叫**结构效应**——只看总数会得出完全错误的结论。

**这一段的板书金句：** "**总数变了，不等于任何一个组成部分变了。**"

### 第 4 步 · 出图（4 分钟）：讲"图要服务结论"

展示 3 张图，讲各自的活儿：
| 图 | 回答什么问题 | 设计取舍 |
|---|---|---|
| 图 1 上周每日走势 | 一周的节奏长什么样、哪天是高峰 | **单一系列**，全部同色蓝——不按高低给不同颜色 |
| 图 2 各门店两周对比 | 谁在涨谁在跌 | 两周用两个固定颜色 + 图例，**并排分组**，可比 |
| 图 3 各门店环比 | 涨跌幅度、谁拖后腿 | **涨绿跌红**——这里颜色编码的是"方向"，不是"大小"，所以用双色是对的 |

**关键提问：**
> "为什么图 1 七根柱子都一个颜色，图 3 却红绿分明？"

答：图 1 比的是**同一个度量的高低**（大小），图 3 比的是**涨还是跌**（方向）。**颜色是给'方向/身份'用的，不是给'大小'用的。**

### 第 5 步 · 出日报（4 分钟）：讲"结论必须长在数据上"

展示日报里的一条结论：
> "上周大区销售额 1,116,320 元，环比 +4.07%；其中广州天河店是四家店中唯一下滑的门店，销售额 205,900 元，环比 −12.13%，建议核查。"

拆解这句话的结构：**现象 → 具体数字 → 对比基准 → 可执行动作**。

**关键提问：**
> "如果我写成'天河店下滑，大区整体增长承压，需警惕'——问题在哪？"

答：前半句"大区增长承压"**数据不支持**——大区明明 +4.07%，是增长的。"天河下滑"（局部）推不出"大区承压"（整体）。**AI 很容易顺着你的话说，所以"不夸大、只讲数据能支撑的"这件事必须由人守。**

## 收尾（7 分钟）：从"做完这一次"到"以后每个周一"

### 对比表（板书/投屏）

| | 手工 | 本次链路 |
|---|---|---|
| 取数切周 | 肉眼框选，易框错周 | 按日期自动切分 |
| 汇总 | 逐个 SUM | 脚本一次算全 |
| 环比 | 容易减反方向/漏负号 | 固定口径，符号正确 |
| 客单价 | 容易用简单平均 | 固定加权口径 |
| 套模板 | 手工改标题日期 | 脚本填模板 |
| 导 PDF | 另存 + 检查串页 | 一次导出 |
| **耗时** | **30–40 分钟** | **分钟级** |
| **下周一** | **再来一遍** | **换一份流水表，重跑一次** |

### 收束提问（回扣痛点卡）

> "今天真正省下来的，是那 30–40 分钟吗？"

引导到正确答案：**省下来的是"发错了才发现"的风险，和"下周一还要再来一遍"。**

### 留给学员的一句话

> "你不需要会做报表。你需要会**说清楚你要什么**，以及**看得懂结果对不对**。"

## 板书/PPT 要点（备查）

1. 一个动作：按周切分（表里混几周都不怕）
2. 一个符号：环比有正有负，天河是负的
3. 一个口径：大区客单价用加权（311.56），不用简单平均（297.50）
4. 一层真相：总数降 ≠ 每部分降（结构效应）
5. 一条红线：结论必须长在数据上，不放大
