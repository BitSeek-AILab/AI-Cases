# 讲课大纲 · 案例10-1 教案框选即改（人机双写·教案）

## 一、本案例在手册里的位置

第10章"新功能实战：框选即改"。

手册结构：先讲**新功能的入口**（「动手前：先学会进入'人机双写'」——两条路径打开可编辑预览、两种状态分清手动编辑 vs AI 编辑、两个易漏步骤：不选中不点按钮 AI 不动手 / 发完还要到对话区再点一次"发送执行"），再给**四个场景**。

本案例 = **场景一：人机双写·教案，框一段就改**。它是四个场景里的第一个，也是"框选即改"最纯粹的一次演示：**只改一段，其余一个字不动**。场景二（成绩）、场景三（课件）都是它换了个文件类型，场景四（集体备课）把它放大到多人。

## 三、手册已给的锚点（照着对齐，不另起炉灶）

1. **入口判断标准**（原文）："WorkBuddy右侧打开了一份能编辑的文档预览，选中内容后弹出「AI编辑」按钮，就进入了。"
2. **两种状态**（手册表格原文）：手动编辑=不用 AI 也不消耗额度；AI 编辑=先选中、点按钮、输指令，"AI 只在你选中的范围里改"。
3. **两个易漏步骤**（原文）：① "不选中内容、不点「AI编辑」，AI是不会动手的"；② "还要到对话区再点一次'发送/执行'按钮，AI才开始改"。
4. **本案例的直接复制指令**（手册原文）："这段导入太干，改成更适合七年级学生的开场：具体到老师说什么、学生做什么，3分钟内让学生进入'春天'的状态。"
5. **手册承诺**（原文）："它只改你框选的那一段，教案其他地方一个字不动，格式也不乱。改完还会告诉你改了哪几处。"
6. **手册提醒**（原文）："AI改的是表达，改不了事实。教案里的学情、课时、学校要求，框选的时候自己先看清楚，别让它把'40分钟'改成'45分钟'都不知道。"

## 四、手册的两条"进阶"（本案例记为可选，主案例只走基本流程）

- 进阶一：一次框好几处，一起改（选中多段 → 加进同一个编辑框 → 一起发送）。
- 进阶二：先出初稿，再选区精调（"改的是段落，不是整篇重来，越改越稳"）。
- 本案例只做手册主流程（框一段、改一段），进阶留作课堂延伸讲解，不落产物。

## 五、本案例自加要求（来自任务卡，非手册）

- 因为"只动选中段"是**唯一红线**，本案例把"其余不变"做成**可机器验证的证据**：解包新 docx 与原件逐字符比对，证明除选中区外 XML 完全相同（比"目测没变"强）。
- 产出**独立的 `改动说明.md`**（手册承诺"告诉你改了哪几处"，本案例把它落成一份可核对的清单）。
- 明确**选中区边界**：只框"第 1/2/3 分钟"三段；**同属导入的"教学过程总表"那一行不框、不改**——并把这件事如实写进改动说明（这正是手册提醒"自己先看清楚"的落点）。
