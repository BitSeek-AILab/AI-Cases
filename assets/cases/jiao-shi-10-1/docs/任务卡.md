## 要解决什么（承接痛点卡）

把"改一小段要**把整份教案贴回聊天框 → 复制回来**（格式全乱、还得逐段核对）"变成"**框住那一段 → 说一句要改成什么样 → 只那段变，其余一个字不动**"。本案例交给 AI 的是手册给的**原句指令**。

## 手册原文指令（照着执行，不擅自改）

> "这段导入太干，改成更适合七年级学生的开场：具体到老师说什么、学生做什么，3分钟内让学生进入'春天'的状态。"

配套动作（手册"操作就四步"）：
1. 打开第06章那份《春》的教案
2. 用鼠标**框选"导入"环节那段文字**
3. 点「AI编辑」，输入上面那句指令，发送，再到对话区点一次"发送/执行"，看它改
4. 核对：只改了框选段 / 其余没动 / 它告诉你改了哪几处

## 最终交付物清单

1. `输入素材/《春》第一课时教案.docx` —— 第06章产物副本（原件不动）。
2. `阶段1_选中与改写/` —— ① 标出"选中区"（原文逐字抄录）；② 改写后的新导入段；产物 + `阶段记录.md`。
3. `阶段2_替换与校验/` —— 把新段**替换回 docx**（只动选中区），并做**逐字比对校验**证明其余不变；产物 + `阶段记录.md`。
4. `最终产物/《春》第一课时教案_导入已改.docx` —— 真 `.docx`，能打开。
5. `最终产物/改动说明.md` —— **"改了哪几处"**（手册承诺的交付项，本案例的核心证据）。
6. `过程记录.md` —— 逐步记录 + 关键校验证据。
7. `审查配置/reviewer-brief.md`、`自检表.md`。

## 统计口径（写死，供审查与复核）

- **选中区（定义）**：教案正文"五、教学过程"之后、`六、赏析支架`之前的 **`【导入】3 分钟逐分钟脚本` 下辖的 3 个段落**（即"第 1 分钟／第 2 分钟／第 3 分钟"三段）。这是老师"用鼠标框住的"那一段文字。
- **不变区**：除上面 3 段之外的**全部内容**——包括**同属导入环节**、但位于"教学过程总表"里的那一行摘要单元格（`导入 / 3′` 行）。
  - ⚠ 这一行**故意不改**：它不在框选范围内。这正是"框选即改"的真实行为，也是手册提醒"框选的时候自己先看清楚"的意义所在（详见 `最终产物/改动说明.md`）。
- **判定"其余一个字不动"的方法**：解包新 docx 的 `word/document.xml`，与原件逐字符比对 → **除选中区那一段字节区间外，两个 XML 应当完全一致**。

## 验收点（供自检与审查）

- [ ] 真实读取 `输入素材/《春》第一课时教案.docx`，无编造原文。
- [ ] 选中区逐字抄录准确（与原件一致）。
- [ ] 新导入段满足手册口径：**更适合七年级 / 具体到老师说什么、学生做什么 / 3 分钟内进入"春天"状态**。
- [ ] **只动选中段**：解包比对证明，除选中区外 `document.xml` 逐字符完全相同。
- [ ] **事实不被改动**：课时（40 分钟 / 第 1 课时）、学情（40 人 / 分析手法弱）、结构（盼春—绘春—赞春）等**一个都没被改**。
- [ ] 产出真 `.docx`，能被 Word/WPS 打开；段落样式、字体、字号与原件一致（未掉格式）。
- [ ] `改动说明.md` 写清"改了哪几处"，逐条可就地核对。
- [ ] 手册提醒的"框选时先看清楚事实"被真实执行（有核对记录）。

## 红线

- 不许重写整篇；**只允许改选中区那 3 段**。
- 不许编造教案原文；选中区文字要能从 `输入素材/` 原样复算出来。
- 不许只描述不产出；`最终产物/` 必须有真能打开的 `.docx`。
- 不许悄悄改到事实（课时、学情、结构名称）——改到了就是打回。
