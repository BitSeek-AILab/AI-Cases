## 要解决什么（一句话）
运营者只想说一句"写篇 XX 主题的推文并发布"，却要自己走完查资料→写稿→排版→配封面→建草稿的 30-60 分钟流程；本案例把这条链路交给 AI，**能自动的自动，必须人工的明说**。

## 关键步骤（严格照手册顺序）

1. **查资料**（对应 M3 Step 1）——先检索"微信小程序更换管理员的操作步骤"，保证**有据可查、不是 AI 瞎编**。
2. **写推文**（对应 M3 Step 2）——生成结构完整推文：更换前准备 + 5 步标准流程 + 紧急申诉方案 + 高频 Q&A + 速查表，约 2000 字。
3. **排版成公众号 HTML**（对应 M3 Step 6 的草稿正文）——Markdown → 微信兼容 HTML。
4. **出封面图**（对应 M3 Step 5）——生成蓝色系、微信小程序主题封面。
5. **建草稿 / 物料包**（对应 M3 Step 6）——产出可直接上传的图文草稿物料。

- `anysearch`（查资料）

## 平台边界（本案例核心教学点）
- **能自动**：查资料、写稿、排版、生成封面、调 API 建**草稿**。
- **必须人工**：① 提供 AppID/AppSecret；② 加 IP 白名单；③ **点"发布"**（未认证订阅号只能建草稿，不能 API 群发）。
- 本机无公众号凭证 → 自动建草稿这一步做**等价替代**（产出可上传的 HTML 物料包），标注【等价替代】。
