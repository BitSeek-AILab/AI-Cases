# 平台边界说明 · 哪些能自动做，哪些必须人工做

> 本案例**核心教学点**（对应 `案例清单.md` 自媒体-06「平台边界与降级」）。
> 手册 M3 原文：「订阅号（未认证）限制：微信官方的群发接口（一键发布给所有粉丝）仅对认证服务号开放。未认证订阅号通过 API 只能创建草稿，还需要你手动在后台点击"发布"。」
> 手册评价：「**有边界感**：遇到平台限制…WorkBuddy 会如实告诉你，不会忽悠你。」

---

## 一、总表：这条链路里，谁做什么

| # | 环节 | 能自动？ | 说明 |
|---|---|---|---|
| 1 | 选题 / 定主题 | ✅ 自动 | 用户给一句话主题即可 |
| 2 | 查资料 | ✅ 自动 | 检索官方文档，保证"有据可查" |
| 3 | 写稿（约 2000 字，四段结构） | ✅ 自动 | 模型生成 |
| 4 | 排版（Markdown → 公众号 HTML） | ✅ 自动 | 生成本页可粘贴的 HTML |
| 5 | 配封面（21:9 + 1:1） | ✅ 自动 | 生成封面 PNG |
| 6 | **提供 AppID / AppSecret** | ❌ **必须人工** | 凭证只能人给；AppSecret 需**管理员扫码**生成且**只显示一次**，务必保存 |
| 7 | **配置 IP 白名单** | ❌ **必须人工** | 微信要求调用 API 的服务器 IP 在白名单内；首次调用必被拦截 |
| 8 | 上传封面素材 / 创建图文**草稿** | ✅ 自动 | 需第 6、7 步就绪；调微信草稿接口 |
| 9 | **点"发布"（群发给粉丝）** | ❌ **必须人工** | **未认证订阅号无法 API 群发**，只能人工在后台点"发布" |

**一句话**：**能自动的是"内容生产 + 建草稿"，必须人工的是"给凭证 / 加白名单 / 点发布"。**

---

## 二、边界背后的平台规则（为什么不能全自动）

1. **群发接口权限**：微信官方群发接口（一键发布给所有粉丝）**仅对认证服务号开放**；**未认证订阅号通过 API 只能创建草稿**。
   → 所以"一句话让 AI 自动发布"这个目标，**平台层面就不允许**，只能做到"自动建草稿"。
2. **凭证安全**：AppID/AppSecret 是账号钥匙，必须由**管理员本人**在微信开发者平台扫码生成；AppSecret **只显示一次**，丢了要重置。
3. **IP 白名单**：微信要求**调用 API 的机器 IP** 必须在白名单里，否则首次调用即被拒绝。

> 手册 M3 实录中，WorkBuddy 在这些地方的表现是：**主动要凭证 → 撞白名单 → 直接给"加白四步" → 如实告知订阅号限制**。这正是"**AI 说清边界，比假装能做到更有价值**"。

## 三、本复刻的【等价替代】

本机**没有公众号凭证**（无法提供真实 AppID/AppSecret，也不应伪造），因此**第 8 步"自动建草稿"无法真实执行**。

**【等价替代】** = 产出**可直接上传的草稿物料包**，人拿到后按 3 步就可得到与"自动建草稿"等同的结果：

```
最终产物/公众号HTML/article.fragment.html   ← 公众号编辑器可直接粘贴的正文
最终产物/封面/wechat-21x9-cover.png         ← 主封面（上传为封面素材）
最终产物/草稿物料包/draft_payload.json      ← 草稿接口载荷（回填 thumb_media_id 后可直接调用）
```

**人工补齐 3 步即可完成"发布"**：
1. 打开公众号后台 → 新建图文消息 → 把 `article.fragment.html` 的正文**粘贴**进编辑器（样式随内联样式保留）；
2. 上传 `wechat-21x9-cover.png` 作封面（可得 `thumb_media_id`）；
3. 填标题/摘要 → **人工点"发布"**。

→ 与手册实录取到的结果一致：**草稿就位，最后一下点发布留给人。**

## 四、给运营者的"期望管理"话术（讲课时可直接用）

> "你想要的'一句话自动发出去'，**能做到的是**：帮你查资料、写好稿、排好版、配好封面、建好草稿；
> **做不到的是**：替你在后台点那个'发布'按钮——因为微信规定未认证订阅号不给 API 群发权限。
> 这不是工具不行，是**平台规则**。谁跟你说能全自动一键发布，那是在忽悠你。"

## 五、凭证与白名单配置指引（对应 M3 Step 3/4，以人工纠正后的路径为准）

> 手册原文提到「由于新旧版本不一样，（AI给的路径不正确）我附上操作路径」——**说明配置引导要按新版路径写**。

**A. 拿 AppID / AppSecret**
1. 打开**微信开发者平台**，左上角选择「公众号」；
2. 进入「**开发密钥**」区；
3. 在 AppSecret 后点击「启动」，**管理员扫码**自动生成；
4. **生成的 AppSecret 一定要保存**（只显示一次），这是自动发文的**重要凭证**。

**B. 加 IP 白名单（首次调用 API 必做，约 1 分钟）**
1. 打开**微信公众平台后台**；
2. 左侧菜单：**设置与开发 → 基本配置**；
3. 找到「**IP 白名单**」一栏，点击「修改」；
4. 添加**调用 API 的机器 IP**（M3 实录中为 `113.77.80.232`，实际以你的机器为准）。

---

## 六、红线提醒
- 本案例**不伪造、不索取**真实公众号凭证；
- 无凭证时**不得声称已"自动发布"**，只能交付【等价替代】物料包并如实标注；
- 涉及发布动作，**一律由人工在公众号后台确认**。
