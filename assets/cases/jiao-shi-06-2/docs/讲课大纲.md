# 讲课大纲 · 案例06-2 学期计划表 → 批量生成教案

> 手册第06章第四节"案例二：学期教学计划表，批量生成教案（预备周场景）"如何展开。
> 本案例是**复刻工程中的实操案例**，我作为"照着手册实操的中职一年级信息技术老师"走完整流程。

## 一、案例在章节中的定位

第06章主线：**教案不是"写"出来的，是"填"出来的** → 三步法"先骨架，后血肉，再打磨"。
- 案例一（第06-1）：**纵向深挖**一份教案（单篇《春》），走"骨架→血肉→打磨"。
- 案例二（本案例）：**横向铺开**一批教案（整学期计划表 → 批量教案），走"读表出框架 → 一次性批量生成"。

两者共用同一根线：**先确认方向（框架），再展开细节**。区别在于案例二把"方向"锚定在**已有的学期计划表**上。

## 二、案例展开的六个动作

### 动作0 · 领任务（本案例起点）
读第06章案例二，提取痛点："预备周填完表，每周还得单独写教案，**同一份工作做两遍**"。
→ 落 `痛点卡.md` / `任务卡.md`。

### 动作1 · 备弹药
读计划素材 `.xlsx`，准备 `xlsx`（读表）+ `docx`（批量出 Word）两类能力。
→ 落 `skill清单.md`；跑之前先写 `审查配置/reviewer-brief.md`。

### 动作2 · 第一步·读表出框架
**手册指令**（原文）：
> "打开…'计划素材_中职一年级信息技术_学期教学计划.xlsx'，这是我的学期教学计划表，每一行是一周，包含周次、单元、本周3节课课题、思政元素。请你先给我一个整学期的教案框架：每周课题对应的核心教学目标、教学重难点等。先给框架，不要展开全文。"

**期望结果**（手册）：读完整表 **20周、7个单元**，对标 WPS 一级考试，给出**整学期教案框架**（总体脉络 + 逐周的核心目标/重点/难点），**不展开**。

→ 落 `阶段1_框架/整学期教案框架.md`。

### 动作3 · 第二步·一次性批量生成（最"哇塞"的一步）
**手册指令**（原文）：
> "继续用这份计划表，把期中考试前的10次课（计划表里的第1节到第10节）一次性批量生成教案，输出成一份《期中考前10课教案合集》，带 Word 格式，带目录。每节课统一结构：教学目标、教学重难点、教学过程（导入→新授→练习→小结→作业，每个环节标注时间）、作业布置。每份教案结构清晰，环节能直接上课，思政元素按表里对应的自然融入，不要生硬说教。10份一次全部给出来。"

**期望结果**（手册）：一次性吐出 10 份教案，每份结构统一、环节清楚；产出**带目录的《期中考前10课教案合集》**。

→ 落 `阶段2_批量/` 与 `最终产物/《期中考前10课教案合集》.docx`。

### 动作4 · 自查 + 交审
对照验收点打勾 → `自检表.md`；按 `审查配置/reviewer-brief.md` 激活审查 Agent 复审。

## 三、关键判断：什么是"前10次课"

手册在本节末尾给了**决定性线索**：
> "剩下的课，同一句指令把范围换成'**第11节到第20节**'就行。"

全学期共 **20 周**。"第1节到第10节"与"第11节到第20节"正好**首尾相接、穷尽 20 周**——说明此处的"节"指的是**周次**（每周3节课为一"周次课"）。

再对照手册给出的产物结构：
- **教案速览表**标题为"本合集10份教案的**周次**…一览"，表内 **10 行 = 第1周…第10周**；
- **目录**为 `第1周教案…第10周教案`，每周下含 `课时一/二/三`。

三处互相印证：**"前10次课" = 第1–10周**，即 **10 份周教案 × 每周3课时 = 30 份课时教案**。

> 注：这与手册"5-10份是好粒度，不一次整学期"的粒度建议一致——10 份（周教案）正好在此区间上沿。

## 四、粒度与后续（手册原文）
> "为什么不一次性生成整学期？内容越多，单份质量越容易飘，改起来也累。5-10份是个好粒度，先批量拿下'量'，再挑重点逐份打磨。"
> "批量生成的是一批能直接用的初稿。真正上课前，挑几份重点的，用案例一的'骨架-血肉-打磨'再打磨一遍。"

→ 本案例严守粒度，**只做前10周**，不贪多；并在产出中体现"初稿"定位。

## 五、思政融入的处理原则
- 计划表最后一列"融入的思政元素"是**每节课思政的唯一锚点**（如第1周"科技强国、职业理想"，第5周"精益求精、工匠精神"）。
- 融入方式：写进**教学目标的"情感态度与价值观"**一条 + 落在**教学过程某一环节的"设计意图"**里，由知识本身**自然生发**，不贴标签、不单列说教段。

---
**一句话**：填一次表，整学期的教案有了起点；先读表出框架，再一次性批量拿下前10周——把预备周的规划，直接变成能上课的教案初稿。
