# 任务卡 · 案例06-2 学期计划表 → 批量生成教案

| 项目 | 内容 |
|---|---|
| **案例名** | 学期计划表 → 批量生成教案（预备周场景） |
| **所属章节** | 第06章《教案撰写：从空白到成稿》· 第四节 案例二 |
| **角色** | 中职一年级信息技术老师（对照 WPS Office 一级考证，每周3节，全学期20周） |
| **场景** | 预备周 |
| **要解决的痛点** | 预备周填完学期计划表后，每周还得单独写一遍教案，"同一份工作做两遍"；且每份教案从空白开始，费时费力 |
| **最终交付物** | 一份**带目录的 Word《期中考前10课教案合集》**（.docx，A4 可打印） |

## 交付物清单

1. **输入素材**
   - `输入素材/计划素材_中职一年级信息技术_学期教学计划.xlsx`（20周/7单元/60课时 + 思政元素）

2. **阶段1 · 读表出框架**（`阶段1_框架/`）
   - `整学期教案框架.md` —— 读表后给出的整学期教案框架：每周课题对应的**核心教学目标、教学重点、教学难点**（先给框架，不展开全文）

3. **阶段2 · 批量生成**（`阶段2_批量/`）
   - 30 份课时教案的结构化内容（10 周 × 3 课时）
   - 每份统一结构：**教学目标 / 教学重难点 / 教学过程（导入→新授→练习→小结→作业，每环节标时间）/ 作业布置**

4. **最终产物**（`最终产物/`）
   - `《期中考前10课教案合集》.docx` —— 含 **教案速览表 + 目录 + 30 份课时教案**

## 统一结构（每课时）
- 一、教学目标（知识能力 / 过程方法 / 情感态度价值观-含思政）
- 二、教学重难点（重点 / 难点）
- 三、教学过程（45分钟，环节表：环节·时间 / 教师活动 / 学生活动 / 设计意图）
- 四、作业布置（必做 / 选做，写清"要交什么"）

## 验收点
- [ ] 产物是**真的能打开**的 .docx，**带目录**（Word 目录域）
- [ ] 覆盖 **第1周–第10周**，共 **10 份周教案 / 30 份课时教案**
- [ ] 30 份教案**结构统一**
- [ ] 每课时教学过程**环节齐全且标注时间**，时间合计 45 分钟
- [ ] **思政元素按计划表对应**自然融入，不生硬说教
- [ ] 遵循手册"5-10份是好粒度，不一次整学期"的粒度要求

- `过程记录.md`（全流程逐步记录）
- `skill清单.md`（用到哪些 skill、路径、用途）
- `审查配置/reviewer-brief.md`（跑之前写好的审查要求）
- `自检表.md`（对照验收点逐条打勾 + 审查结论）
