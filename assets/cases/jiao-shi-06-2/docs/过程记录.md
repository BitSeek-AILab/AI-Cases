**和手册预期一致吗**：✅ 手册期望"读完整表 20 周、7 个单元……给出整学期教案框架，先不展开"——本阶段完全对齐。

## 步骤3 · 第二步·一次性批量生成（阶段2）

**调用的 skill**：`docx` skill（+ Node 库 `docx@9.10.0`，复用 `tmp_local/_probe_docx/node_modules`，不重复下载）。
**给的输入**：手册第二步指令（原文照抄，见 `阶段2_批量/阶段记录.md`）。

**关键判断（"前10次课"是什么）**：
手册末尾给线索——"剩下的课，同一句指令把范围换成'**第11节到第20节**'就行"。全学期 20 周，"第1–10节"与"第11–20节"正好收尾相接、穷尽 20 周 → **此处的"节"= 周次**。再对照手册产物：速览表标题"本合集10份教案的**周次**…一览"（10 行 = 第1–10周）、目录为"第1周教案…第10周教案"（每周含课时一/二/三）。三处互证 → **前10次课 = 第1–10周 = 10 份周教案 / 30 份课时教案**。

**做了什么**：
1. 将 30 份课时教案**结构化**写入 `_build/lessons_data.js`（内置断言：课时数=30、每课时时间合计=45）。
2. `_build/build_collection.js` 一次性生成 docx：封面 → 教案速览表 → **目录（Word TOC 域）** → 正文（逐周逐课时）。
3. `_build/dump_md.js` 生成可读内容稿。
4. `_build/verify_docx.py` 校验产物。

**得到的结果**：
- `最终产物/《期中考前10课教案合集》.docx`（46,953 字节）
- `阶段2_批量/期中考前10课教案合集_内容稿.md`
- `最终产物/《期中考前10课教案合集》_预览版.pdf`（LibreOffice 渲染的 34 页预览）

**和手册预期一致吗**：✅ 手册期望"一次性吐出 10 份教案，每份结构统一、环节清楚……带 Word 格式，带目录"。本产物：10 份周教案 / 30 份课时、结构由同一模板渲染**完全统一**、**带目录**、环节可直接上课、思政按表融入。

**踩坑与修复（重要）**：
1. **空列 bug**：首版 docx 的教学过程表"教师活动/学生活动/设计意图"三列**全空**（速览表"单元/思政主题"列同样空）。根因：表格单元格构造器 `cellP()` 收到 **TextRun 对象**时被当成字符串又包了一层 `t()`，导致文本变 `undefined`。→ 修 `cellP()` 兼容"字符串 / TextRun / 数组"三种入参；重建后从 33,849 字节 → 46,953 字节。
   - 该 bug 起初**逃过了**内容校验（因为"导入/新授/练习"等环节名来自数组入参的单元格，仍存在）。→ **加固校验**：`verify_docx.py` 增补只在"教师/学生/设计意图"列出现的文本（如"自由举例""以熟悉生活切入"）作为回归哨兵，现全部 OK。
   - **这一坑靠"渲染成图 + 人眼目检"才发现**，说明"只跑文本校验"不足以证明版式可用。
2. **目录页码**：目录采用 Word TOC 域（`TOC \h \o "1-2"`），含 **40 条缓存条目**（10 周 + 30 课时）与 `PAGEREF` 页码域；并设置 `updateFields=true` + 域 `dirty=true`，Word/WPS 打开即自动填页码（附"Ctrl+A、F9"提示）。
   - 尝试用 LibreOffice UNO 刷新目录后导出 PDF，LO 反而**清空**了 Word TOC 域的条目 → **放弃该方案**（docx 文件本身未被改动）。
   - 最终预览 PDF 采用普通转换：目录条目完整可见，页码留空（LO 无头转换不计算域页码），docx 为正产物。
3. **编码坑**：Windows 控制台 GBK，`python` 直接 print 中文乱码 → 脚本 `open(..., encoding="utf-8")` 写文件后读取。
4. **JS 引号坑**：Markdown 导出脚本内中文引号误用致语法错误 → 修正。

## 步骤5 · 自查 + 交审

- 自检：`自检表.md`（对照 8 条验收点逐条打勾）。
- 交审：按 `审查配置/reviewer-brief.md` 激活**能读文字**的审查 Agent 复审。

### 审查第一轮：**打回**（8 条中 7 条 ✅）
审查 Agent 独立解包 docx 复核后指出：**验收点 6「思政逐课对应」不满足**——周级锚点（速览表、课时表头）正确，但有 **5 份课时教案的正文（教学目标第 3 条 + 设计意图）落到邻周的思政元素**，当周元素在正文缺位：
- 第1周课时3 → 落到"严谨"（属第2周）
- 第2周课时2 → 落到"自主创新"（属第4周）
- 第2周课时3 → 落到"责任意识"（属第3周）
- 第4周课时2 → 落到"文化自信"（属第7周）
- 第7周课时3 → 落到"条理规范"（属第3/8周）

### 整改（只改内容，未动版式/结构）
1. 逐课改写"教学目标(3) + 设计意图"，使**每课时都显式含当周思政元素**；上述 5 处全改（如第7周课时3 把练习改为制作"中华传统节日一览表"，自然落"文化自信、审美素养"）。
2. 顺带修复**同类问题 7 处**（第1周课时2、第5周课时14/15、第8周课时22/24、第10周课时29/30），并把简写标注补全（"精益"→"精益求精"、"强调严谨"→"严谨求实"、"节约、负责"→"条理规范与责任意识"）。
3. 新增**自动化思政四维自检**（可 `node` 复跑）：obj3 显式含当周元素 30/30、思政标注 0 例外、跨周元素污染 0、载体含当周 30/30。
