## 三、数学与文字正确性（逐个数字核对）

| 卡片上的断言 | 核对 | 结果 |
|---|---|---|
| 1/3 = 4/12 | 3×4=12；1×4=4 | ✅ |
| 1/4 = 3/12 | 4×3=12；1×3=3 | ✅ |
| 12 是 3 和 4 的最小公倍数 | 3×4=12 且互质 | ✅ |
| 1/3 + 1/4 = 4/12 + 3/12 | 通分正确 | ✅ |
| 4/12 + 3/12 = 7/12 | 4+3=7，分母不变 | ✅ |

| 错解：1/2 写成 1/4+1/4 → 正解：1/2 = 2/4 = 3/6 | 只通分母忘通分子确实会得 1/4+1/4=2/4 的形式错；1/2=2/4=3/6 | ✅ |
