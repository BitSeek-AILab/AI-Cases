# 讲课大纲 · 案例04-4（知识卡片怎么在课堂与课后用）

> 手册在本形态只给了主题、一句四件套指令和一段 Baoyu Infographic 的交互记录，没有逐步流程。本文件把"这张卡怎么用"写清楚。

## 一、案例如何展开（复刻视角）

手册给出的路径：**Baoyu Infographic（设计师）+ 画师（出图）** 两段式。手册的原文拆解：

> "Baoyu Infographic 干的事，是把内容组织好：分析内容 → 选布局（21种）→ 选风格（22种）→ 写结构化内容 → 写 prompt。到真正'出图'那一步，它其实需要一个画师 baoyu-image-gen 来接手。"
> "配在一起的逻辑特别清楚：baoyu-infographic 管脑子，baoyu-image-gen 管手。"

手册还给了两种"只用一半"的用法：只用画师（已知要画什么时）、只用设计师（流程完整但最后用内置引擎出图，效果打折）。

**本案例走完整两段式**：设计师段复刻在 `阶段1_内容分析与设计/设计稿.md`，画师段见 `阶段2_出图与校验/`。

## 二、这张卡在什么时候用

| 时机 | 用法 |
|---|---|
| 下课前一分钟 | 老师把卡片投出来，全班一起读一遍口诀"先通分，再计算，能约分的要约分"，然后发到班级群 |
| 课后 · 当天 | 学生手机点开，把"为什么要通分"的分数条再过一眼 |
| 课后 · 写作业时 | 卡在"三个坑"那一栏对着检查自己的作业（公分母找错了吗？约分了吗？） |
| 单元复习 | 集齐本单元几张卡，就是自己的一份复习资料；截图归档即可 |
| 家长端 | 发群里，家长也知道这节课学了什么、孩子该会什么 |

## 三、这张卡的设计取舍（讲给老师听的话术）

> "一张复习卡不是把教案缩印。课上讲过的流程、目标、重难点，学生不需要再背一遍；**他需要的是'会忘的那几样'**。
> 所以这张卡只留了五块：一句口诀、一个'为什么要通分'的图示、三步方法配一道例题、三个坑的错解/正解对照、一道课后一练。
> 尤其是那四条分数条——**没有老师讲，卡片自己也得把'1/3 和 4/12 一样长'这件事说清楚**，这就是它跟一张漂亮海报的区别。"

## 四、与另三种形态的关系（一节课的完整闭环）

| 形态 | 发生在 | 角色 | 有效期的终点 |
|---|---|---|---|
| 一 · 课堂 PPT | 课堂上 | 老师讲、学生看（放着看的） | 下课铃 |
| 二 · HTML 网页课件 | 课堂上 | 老师讲、算理会动 | 下课铃 |
| 三 · 互动课件 | 课堂上 | **学生上手**玩、练 | 下课铃 |
| **四 · 知识卡片** | **课后** | **学生自己带走、自己复习** | **没有终点（存在学生手机里）** |

> "同一节课，你备一次，四种形态。课堂上讲得清、玩得动，下课后学生还能带着复习。"
> —— 手册第04章收束语

**形态四是唯一跨过下课铃的那一个。** 这句话是本案例最值得讲给老师听的点。

## 五、操作提示（老师用）

1. 卡片 PNG 直接发班级群（微信/钉钉均可，手机上点开即看，无需任何软件）。
2. 想改内容：编辑 `最终产物/分数加减法_知识卡片_源文件.html`，然后跑
   `node render_card.mjs <card.html> <out.png> 2` 重新出图（带版面溢出体检，溢出会拒绝出图）。
3. 想换风格或交给 AI 画师出图：把 `阶段2_出图与校验/出图prompt.md` 第一节的 prompt 原样投喂给即梦 5.0 / image2 等画师即可。
4. 想批量做整套单元卡：把本案例的 `出图prompt.md` 当模板，只换"内容"段（`--- EXACT COPY ---` 那部分）即可。
