## 要解决什么（承接痛点卡）

把"下课之后，学生翻笔记翻课本，很多学生下课就忘了"变成"**手机里有一张自己的复习卡，碎片时间翻一翻就复习了**"。
—— 这是四种形态里**唯一一个脱离老师、脱离教室还能工作**的产物，因此它必须**适合手机**且**自解释**。

## 验收点（供自检与审查）

- [ ] 产出是**真图片**（PNG），能打开、能看、能发群。
- [ ] **竖版 9:16**，实测像素比例 = 0.5625。
- [ ] **中文零乱码**，字形完整、无缺笔、无重叠。
- [ ] **所有算式数字正确**（逐个核对，含 1/3=4/12、1/4=3/12、7/12、5/6−1/4=7/12 等）。
- [ ] 分数是**竖式排版**（分子在上、分母在下、中间分数线），不是斜杠。
- [ ] **重点突出**：有明确的视觉层级，口诀/关键结论一眼可见。
- [ ] **版面不溢出、不被裁**：所有模块（含页脚）完整落在 1920px 内。
- [ ] 手册的"设计师 + 画师"两段**都落到实处**：设计师段有真实产出（分析/布局/风格/结构化内容/prompt）；画师段有真实出图。
- [ ] 严格按手册四步（分析内容 → 选布局 → 选风格 → 写 prompt）走，不跳步。
- [ ] 卡片**能真的用于复习**（自解释）：带算理图示 + 易错点对照，不是只有口诀的漂亮海报。
- [ ] 痛点被真实解决（课后断线 → 有东西可带走）。
