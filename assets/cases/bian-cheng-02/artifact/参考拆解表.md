## 二、02 视觉（借：只借"层级手法"；色板字体整段换掉）

> ⚠️ 本段**不写参考站的 hex 色值**（未抓取源码，见 §〇）。只写**公开可描述的流派级特征**与**可迁移的手法**。

| 拆解项 | 参考站的做法（流派级） | 借 / 换 |
|---|---|---|
| **整体明度基调** | **深色底**（暗蓝灰 slate 家族），正文用低饱和冷灰 | **❌ 不借** → **换成浅色冷灰蓝纸底**（与其基调相反） |
| **强调色用法** | **单一强调色**（一个偏青的亮色），只出现在：导航高亮、链接、hover 边框 | **✅ 借"手法"**（**全页只准一处强调色**）；**换色相**（青 → 电紫），**且不复制其色系** |
| **字号跨度** | **极端对比**：姓名/标题字号远超正文，元数据字号很小 | **✅ 借**（同样做大跨度，标题 `clamp` 到 3.4rem，元数据压到 0.75rem） |
| **字体角色** | **单字体方案**（Inter 通吃标题与正文） | **❌ 不借** → **换为"双语双角色"**：**拉丁/数据走等宽 mono**，**中文正文走系统无衬线**（刻意避开 Inter） |
| **次级文字的处理** | 正文/元数据用**低对比冷灰**（拉开层次而不靠加粗） | **✅ 借**（同样三级文字层次：主墨 / 次级 / 元数据） |
| **面的形状** | **圆角卡片** + hover 时描边/抬升 | **❌ 不借** → **换成 0 圆角 + 细实线分隔 + "刻度/测量"母题** |
| **装饰** | 克制，基本无装饰 | **✅ 借"克制"**；**换**成一个**原创 signature**（见 §三·signature） |

**视觉段结论**：**只借三样手法**——① **单一强调色**（全页一处）② **极端字号跨度** ③ **三级文字层次**；
**其余整段换掉**：明度基调（深→浅）、字体（Inter 单字体 → mono+sans 双角色）、面的形状（圆角卡 → 0 圆角细线）、
装饰母题（无 → 测量刻度）。

## 三、03 交互（借：行为与节奏；形态自己定）

| 拆解项 | 参考站的做法 | 借 / 换 |
|---|---|---|
| **滚动与导航联动** | **scroll-spy**：滚到哪个分区，左栏对应锚点文字**变强调色高亮** | **✅ 借行为**（滚动位置 → 当前项指示）；**换形态** → 见 signature |
| **列表行悬停** | hover 时行上浮现一层**径向光斑（spotlight）**，同时行内标题**变强调色**，整行轻微上移 | **✅ 借"hover 给行级反馈"**；**换实现** → **左侧强调色竖条展开 + 行底色提亮 + 元数据由三级色转主墨**（**不做光斑、不做位移**——避免与其观感重合） |
| **入场动效** | 分区内容滚动到视口时**淡入 + 上移**，节奏平缓、幅度小 | **✅ 借节奏**（淡入 + 16px 上移，`IntersectionObserver`，一次性，不重复播） |
| **悬停的启用条件** | 桌面 hover 增强；**移动端用 tap 状态**替代（无 hover-only 交互） | **✅ 借**（`@media (hover:hover)` 才启用 hover 增强；移动端 tap 等效） |
| **无障碍与降级** | 有 skip-link；键盘可达 | **✅ 借**（skip-link + 可见 focus 环 + `prefers-reduced-motion` 关闭全部动效） |
| **彩蛋** | 页脚有一个主题彩蛋（Doctor Who 相关动画） | **❌ 不借**（那是其个人趣味与素材，与"方法"无关） |

**交互段结论**：**借四个行为**——scroll-spy 联动、行级 hover 反馈、滚动淡入、移动端 tap 替代 + 降级；
**全部换实现形态**（导航高亮 → 刻度尺标记；光斑 hover → 竖条+底色；不做彩蛋）。

### ★ 本页的 signature（原创，非借）
**核验刻度尺（Verification Ruler）**：把参考站的"锚点文字导航"换成**一把竖立的刻度尺**——
每个分区在尺上是一个**刻度点**，当前分区由一个**电紫实心标记**指示（滚动时沿尺滑动）。
更有意思的是：**作品列表里的每一项，在尺上也对应一个刻度点，并标出它的核验读数**（如 `6/6`、`15/15`）。

> 为什么是这个 signature：本作品集的主题是"**AI 做的网页，但要拿核验数据说话**"。
> "刻度尺 + 读数"**编码了这件事本身**（把"好不好"变成"量出来是多少"），
> 而不是装饰——正合 `frontend-design` 要求的"**structural devices should encode something true about the content**"。
> 同时它**替换掉了参考站最有辨识度的部件（左栏锚点导航）**，让两者**不会一眼相像**。

### 4.2 明确**没有**借的东西（红线的另一半）

- ❌ 参考站的**姓名、职位、一句话、项目名、页脚文案**——一个字都没用（见 `输入素材\来源说明与原文摘录.md`，那些文字只在该"来源说明"里作为**被观察对象**被记录）。
- ❌ 参考站的**色值 hex、字体文件、图标、图片、CSS/JS 代码**——**未抓取、未使用**。
- ❌ 参考站的**彩蛋/动效素材**。
- ❌ 参考站的**社交外链与其身份信息的位置内容**。

### 4.3 哪些是占位（placeholder）

**本页无占位素材**——正文全部为真实内容，视觉全部用 CSS 画（实线、刻度、排版；核验实测 `<img>` 与 `<svg>` 均为 0 个）。
唯一需要声明的是：**"作品缩略"以"核验读数 + 编号"的排版本体呈现，而非截图**——
这是**刻意的**（`frontend-design`："restraint…cut any decoration that does not serve the brief"，
且满足验收点"不含原站图片"，并让产物保持轻量）。这不是"占位图"，是**主动的设计选择**。

## 六、一页纸小结（给审查人）

| | |
|---|---|
| **借了什么方法** | 布局骨架（两列 + 左栏 sticky + 身份→证据叙事 + 块状低密度列表）；三个视觉手法（单一强调色 / 极端字号跨度 / 三级文字层次）；四个交互行为（scroll-spy 联动 / 行级 hover / 滚动淡入 / tap 替代与降级） |
| **换了什么内容** | 分区与全部文案（含新增"04 边界"）；作品的真实数据；视觉语言整段（明度基调反转、字体双角色、0 圆角细线、测量刻度母题）；导航形态换成原创"核验刻度尺" |
| **哪些是占位** | **无占位素材**。作品缩略以"核验读数排版本体"呈现（主动设计选择，非占位图） |
| **没碰什么** | 参考站的商标 / logo / 姓名 / 职位 / 文案 / 项目名 / 色值 / 字体文件 / 图片 / 图标 / 代码 / 彩蛋 |

> 结论：**同一套"设计语言"（Design Language）**，**不同的"设计身份"（Design Identity）**——
> 像的是"骨架与节奏"，不像的是"脸"。这正是 M6 #36 验收句 `feel like the same design language, not a clone` 的意思。
