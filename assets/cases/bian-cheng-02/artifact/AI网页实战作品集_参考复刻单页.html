01

关于

这不是一份设计稿，这是一份验收记录。

这一页里的每件作品，都是在这个工程里真的做出来的单文件网页。每一件都跑过功能与视觉核验， 作品行右侧那个数字就是它的通过数——量出来的，不是估出来的。

所以版面不承担炫技的任务：它只需要在一条滚动里把「是什么 / 借了什么 / 做出了什么 / 边界在哪」讲完。 导航做成一把刻度尺，也是因为这个——这门课验收的是读数，不是观感；滚到哪一节，尺上的标记就滑到哪一格。

关于参考：本页的版面借自一个被业界广泛研究的作品集范式（左侧粘性身份栏 + 右侧滚动分区）。 借的只有骨架与节奏，不借它的商标、图片、文案或代码——具体划在哪，见下面的「02 方法」和「04 边界」。

02

方法

参考要拆，不能照抄；拆完要换，才算自己的。这就是这一页的做法，拆成三段各借各的。

01 结构 · 借

信息架构与版面逻辑

借两列（左窄右宽）、左栏粘性、以及"由身份到证据"的分区叙事顺序，和"条 = 标题 + 元数据"的低密度块状列表。

02 视觉 · 只借手法

层级手法，不借身份

只借三样：单一强调色全页仅一处、极端字号跨度、靠低对比拉开的三级文字层次。色板、字体、圆角质感整段换掉。

03 交互 · 借行为

行为与节奏

借滚动联动导航指示、列表行悬停反馈、滚动淡入的节奏，以及移动端用点按替代悬停、并给低动效兜底。

02 视觉（只借手法）：单一强调色全页仅一处；极端字号跨度；三级文字层次（低对比拉开）。

03 交互（借行为）：滚动联动导航指示（scroll-spy）；列表行 hover 给行级反馈；
            IntersectionObserver 滚动淡入（一次性）；移动端 tap 替代 hover；
            prefers-reduced-motion 关闭全部动效；可见 focus 环 + skip link。
04 改成自己的：全部文案与数据用我提供的内容；零位图零外链；
            页脚必须明写"借了哪些方法 / 换了哪些内容 / 哪些是占位"。

03

作品

右侧读数是各自的功能与视觉核验通过数。点开一行看它的核验明细。

  • 是什么
    把「定目标 / 给内容 / 给参考 / 生成第一版 / 逐项修改」这套方法本身，做成一个能被一条滚动读完的落地页。
    核验明细
    交付自检六条实测全过：内容真实（占位 0 / 死链 0 / 空图 0）、手机 390 与 320 均不横滚、标签切换与折叠与复制与滚动高亮可用、单一锚点色、页脚含授权说明、单文件离线可开。
    为什么在这
    它是本作品集里"方法论母本"那一件——后面几件的做法都从它来。
  • 是什么
    图片长短不一时的自然下落布局，做成两个版本：简单版用 CSS 多栏，精确版用脚本按列高分配卡片。
    核验明细
    两版均通过视觉验收：20 张卡片自然下落、悬停反馈与加载状态可用、含骨架与加载失败两种状态、手机端不横滚。
    为什么在这
    它演示了"同一个需求，简单做法与精确做法各有什么代价"——这是课上要对比的一组。
  • 是什么
    把 30 个设计向技能做成一个可筛选、可复制的榜单页。
    核验明细
    功能核验 7/7 + 边界补测 4/4 全过；零外链（30 张预览图全部内联）；手机 390 与 320 不横滚；审查方独立复审通过，4 条非阻塞意见修订后重跑通过。
    它教的一件事
    为了让页面"零外链"，作者选择把预览图直接内联进 HTML——代价是文件到 1.34 MB。这就是"零外链"这个决定的价格。
  • 是什么
    把 76 条交互网站提示词做成可搜索、可按分类与标签两层筛选、可分别复制中英文的库。
    核验明细
    功能与视觉核验 15/15 + 边界补测 3/3 全过；零外链；手机 390 与 320 不横滚；审查方独立复审通过并准予交付，3 条非阻塞意见修订后重跑通过。
    为什么在这
    这一件比它的原始成品多了两层筛选、搜索与批量复制——它演示的是"复刻不等于照抄，可以做得更好"。
  • 是什么
    把"参考要拆、拆完要换"这件事本身做成一个可看的产物：骨架借自作品集范式，视觉与内容全部自己的。
    核验明细
    见本页页脚的核验口径；作品行里的每一处数字都可回溯到对应产物的核验记录。
    递归的一件
    它的"参考对象"就是一个作品集页；它的"成品"也是一个作品集页。区别在于借的是骨架，不是脸。
04

边界

复刻最容易翻车的不是技术，是边界：借得太多是抄袭，借得太少是形似神不似。所以这一节写在页面上，供人核对。

借了什么方法

只有方法

  • 布局骨架：两列、左栏粘性、窄左宽右
  • 叙事顺序：由身份到证据
  • 三个视觉手法：单一强调色、极端字号跨度、三级文字层次
  • 四个交互行为：滚动联动导航、行级悬停反馈、滚动淡入、点按替代与低动效兜底
换了什么内容

全部是自己的

  • 分区与全部文案（并新增「04 边界」这一节）
  • 作品的真实数据：卡片数、核验通过数、文件大小
  • 视觉语言整段：明度基调反转、字体双角色、零圆角细线、测量刻度母题
  • 导航形态换成原创的核验刻度尺
没碰什么

红线之外

  • 参考站的商标、标志、姓名、职务、文案、项目名
  • 它的色值、字体文件、图片、图标
  • 它的任何一段代码，以及页脚的彩蛋与素材
  • 本页零外链、零位图：实线、刻度与排版全部用 CSS 画，没有图片也没有图标
哪些是占位

没有占位素材

  • 正文全部为真实内容，无一处占位文案
  • 作品不做缩略图，改用编号 + 核验读数呈现
  • 这是主动的设计选择，不是"图还没换"
  • 页面上的每个数字都能回溯到对应产物的核验记录
