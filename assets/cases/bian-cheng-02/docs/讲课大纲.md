# 讲课大纲 · 案例编程-02 ｜ 参考截图 / URL 复刻网页

> 手册只有"格式要求 + P14 一句话"（M6 格式要求 4 / M4 P14），本大纲把**它展开成一条可讲的线**。
> 讲法定位：**先让学员看见自己会怎么翻车（形似神不似 + 抄袭雷），再给一把三段拆解的尺子，再当场量一遍。**

---

## 一、这节课要让学员带走什么（一句话）

不是"学会扒站"，而是**学会把一句"参考这个站"翻译成 AI 能执行的三段话**——
**结构借什么、视觉借什么、交互借什么，以及哪一段要换成我自己的**，
从而拿到一个**敢发出去的**单页。

## 二、开场（3 分钟）：先让学员"疼一下"

- **提问**：「你有没有过——看到一个网站特别喜欢，截图丢给 AI 说"照这个做"，结果出来一个'差不多但就是不对'的东西？」
- **追问**：「更扎心的是：**做完那一刻你才发现，配色是人家品牌色、图是人家拍的、文案是人家写的**——你敢发吗？」
- **点破**（M6 格式要求 4）：
  `借鉴布局、动效节奏、信息层级和设计系统，不复制受版权保护的素材、商标、图片和完整文案。`
- **落点**（M4 P14）：
  `不要只截图，要告诉 Codex 参考哪里：01 结构 02 视觉 03 交互 04 改成自己的。`

## 三、主体（25 分钟）：一把尺子量四段

> 讲法：**每一段都讲"只截图会怎样 → 说清这一段 AI 才能做什么 → 一个具体量级的例子"**，
> 并在**本案例的真实拆解表**上指出对应位置。

| 段 | 只截图会怎样 | 说清这一段，AI 才能…… | 一句话例子（本案例用） |
|---|---|---|---|
| **01 结构** | 猜不到你喜欢的是**布局** | 复刻**列数 / 粘性 / 分区顺序 / 导航形态**，而不是把所有卡片照抄 | "两列：左栏粘性身份+锚点导航，右栏滚动分区，顺序是 关于→方法→作品→边界" |
| **02 视觉** | 把人家**品牌色照搬**，直接踩版权 | 复刻**层级手段**（对比/留白/字号跨度），但**色板字体自己定** | "借'单一强调色 + 极端字号对比'的手法；颜色我换成纸白底+朱砂" |
| **03 交互** | 只抄到"静态样子" | 复刻**导航行为 / 悬停状态 / 滚动揭示 / 节奏感** | "借 scroll-spy 高亮 + 列表行 hover 反馈 + 滚动渐显，含 reduced-motion 兜底" |
| **04 改成自己的** | **这才是翻车根源** | ——**借方法，不搬运**文案、商标、图片和整站代码 | 见拆解表底部"借/换对照表"：**逐条写明借什么、换什么** |

- **关键提醒 1**（M6 三条提示词各管一段，可组合）：
  - **#44 只复刻信息架构**——"Borrow section order / conversion logic / CTA rhythm；**Do not borrow** visual design, images, icons, exact copy."
  - **#43 只复刻动效节奏**——"borrows the **motion rhythm**, not the visual design."
  - **#38 换皮但保留布局系统**——"**Keep** section order & density；**Change** brand identity, colors, typography, copy, icons, imagery, product examples."
  - **合起来 = 本案例**：结构 + 交互照借，视觉整段换掉。
- **关键提醒 2**（M6 #36 / #69 的 **Deliver** 要求）：交付时必须**附一句说明**——
  "**what patterns were borrowed, what was changed, and which assets are placeholders**"。
  这一句就是**验收凭据**：说不清"借了什么/换了什么"，等于没做完。
- **关键提醒 3**（M6 #42 / #74 第二轮）：第一版之后**别继续加形容词**（"再高级一点"），
  改成**对照截图按优先级修**：布局对齐 → 间距 → 字号 → 颜色 → 状态 → 动效。

## 四、收尾（5 分钟）：交付前只看三件事

1. **能指着段落说清"借了什么/换了什么"**（借/换对照表 + 页脚声明）。
2. **不含原站商标、图片、整站代码**（零外链、零位图、零复制代码）。
3. **能打开、手机能读**（单文件、390 不横滚）。

> 讲法：把"像不像"换成"**借得对不对、换得干不干净**"——这是我们和"抠像素还原度"的分水岭。

## 五、本案例的"当场示范"（这就是复刻要跑的东西）

现场用四段尺子，做一个**真实题材**：**"AI 网页实战作品集"单页**。
- **参考对象**：一个广为人知的作品集布局范式——"左侧粘性身份栏 + 右侧滚动分区"（archetype: `brittanychiang.com` v4）。
- **为什么选它**：三段拆解极清晰（能落到列数/色值/行为级别），且"**结构+交互照借、视觉整段换掉**"
  能把"借/换边界"演到一眼可辨——正好呼应 M6 #43 / #44 / #38 三条提示词。
- **自己内容为什么可靠**：作品数据**全部来自本工程真实产物**（卡片数、核验通过数、文件大小、md5 可逐条回溯）。
- 学员看到的结果：一个**单文件、能双击打开、手机也能看**的作品集页，
  且**页脚就写着一句话声明**："借了哪个布局与交互方法、换了哪些视觉与内容"。

## 七、给学员的课后动作

1. **换一个你自己的参考站**（你最近收藏的那个），**照四段各写一行**：
   结构借什么 / 视觉借什么 / 交互借什么 / 哪一段换成我自己的。
2. 把这三行**直接当提示词**发出去（参见拆解表 §五 的可抄"参考指令"）。
3. 交付前**逐条过三件事**（借换说清 / 不含版权素材 / 能打开且手机能读），
   把不通过的项写下来——**说不清的地方，就是你还没拆开的地方。**
