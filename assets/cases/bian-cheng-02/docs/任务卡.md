## 要解决什么（一句话）

把"**看到喜欢的网站 → 只能截图 + 口头描述 → 出来的东西形似神不似、还抄了人家版权素材不敢用**"，

## 验收点（**本案例专属**，逐条打勾）

1. **明确区分"借了什么方法 / 换了什么内容"**——拆解表有**借/换对照表**，页面页脚有一句话声明，产物说明有专章。
2. **不含原站商标 / 图片 / 整站代码**——零外链、零位图、零复制代码；页内出现的品牌名只作为"**参考对象**"被显式声明。
3. **三段拆解落到具体**——不是"很好看/很高级"这类形容词，而是**列数、色值、字号、交互行为**级别的描述。
4. **单文件 HTML 真实落盘、能打开**——离线双击可开、零外部依赖。
5. **手机可读不横滚**——390 严格判据 + 320 兜底。
6. **内容真实**——无占位文案、无死链、无空图片；作品数据可回溯到本工程的真实产物。

## 参考方向选择说明

**参考对象**：一个**广为人知的作品集布局范式**——"**左侧粘性身份栏 + 右侧滚动分区**"
（archetype 取 `brittanychiang.com` v4 版式；该站源码公开、版式被业界广泛研究，是**布局范式**而非品牌素材）。

**选它的理由**：
1. **三段拆解极清晰**：结构（两列/粘性/锚点导航 · 分区顺序）、视觉（深色 slate + Inter + 青绿强调）、
   交互（scroll-spy 高亮 + 行 hover 光斑 + 滚动揭示）——**每段都能落到具体量级**，教学示范价值最高。
2. **"换自己的"最好演示**：本案例**结构 + 交互照借，视觉整段换掉**（改成纸本档案风），
   让"借/换"的边界**一眼可辨**——这正是 M6 #43"只复刻动效节奏"、#44"只复刻信息架构"、#38"换皮保布局"三条提示词的合体演示。
3. **版权可控**：只借**布局逻辑与交互模式**（方法），不取任何商标、图片、文案、整站代码。

**自己内容的选择**：**"AI 网页实战作品集"**——收录本 `进一步复刻_工程` **真实产出**的编程案例
（编程-01 / 04 / 07 / 09 + 本页自身 编程-02）。
选它的理由与编程-01 同构：**每条数据都能在本工程的真实产物里找到出处**（卡片数、核验通过数、文件大小、md5），
**零虚构风险**，天然满足"内容真实"这条红线。
