## 7. 坑（汇总，详见两阶段记录）
1. **MSYS/Windows 路径**：Chrome `--screenshot` 与 Python 读文件都要 Windows 路径（`cygpath -w/-m`）。
2. **密度欠填**：`grow` 顶底会留中段空白 → 需按 4 横带密度检查补内容。
3. **溢出**：竖版预算紧，页眉下间距/台账行距要收紧。
4. **Python 环境**：anaconda `py 脚本.py` 在**含中文路径**下找不到用户级 site-packages（`import PIL` 失败），`py -c "…"` 正常 → 用 `py -c "exec(open(...).read())"` 绕过。
5. **字体**：种子模板 `Inter` 走 Google Fonts（在线可达，未回退）；中文由**本地 Noto Sans SC** 渲染。
6. **磁盘**：Chrome 临时 profile 放 D 盘、**用完即删**，起前后各看一次磁盘（遵守 `环境限制备忘.md`）。
