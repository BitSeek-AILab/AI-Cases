## 关键步骤（严格照 M7 #24 的能力描述做实）

M7 #24 能力 = 「**生成小红书风格知识卡片…**」→ 拆成 4 步：

1. **定品类路由**——读 `guizang-social-card-skill/references/category-cookbook.md`，判定内容属于哪类小红书品类 → 得到"该用哪套视觉系统 + 哪些版式配方"。
2. **选视觉系统 + 主题色**——按 `style-system.md` / `theme-presets.md` 从 两套系统（电子杂志×电子墨水 / 瑞士国际主义）里**选一套并锁定单一强调色**。
3. **出图**——复制 skill 的**种子模板**（不改原 skill），按配方组装每张卡 → **Chrome headless 截图**导出真实 PNG。
4. **核验**——按 `platform-specs.md`（1080×1440）+ `qa-checklist.md`（4 横带密度 / 溢出 / 触边 / Swiss 硬规则）**插桩实测**并修正。

## 验收点
- [ ] 一组卡片**同一视觉系统、同一强调色**（不是每张一个风格）
- [ ] 每张 **1080×1440**，PNG 真实落盘、可打开
- [ ] 版式**无溢出、不触边、不与页脚碰撞**
- [ ] **4 横带密度**达标（填充+合理留白 ≥100%，实填 ≥75%）
- [ ] Swiss 硬规则：无圆角/无阴影/无渐变；单一强调色；标题"越大越细"（≥72px 用 typed class 且 weight ≤300）
- [ ] 有明确的**品类路由依据**写在 `卡片文案.md`
- [ ] 数字**不编造**（页内出现的数字均为结构标号，非统计）
- [ ] 明确写出**"哪些必须人工做"**（事实核对 / 合规复核 / 发布 / 品牌一致性）
