# 讲课大纲 · 案例04-1 形态一·课堂PPT课件

> 本案例在手册中只有主题（"形态一：课堂课件（PPT），先做你熟悉的"）+ 一张骨架表 + 三步走说明。
> 下面把手册主题展开为可复刻的讲课大纲。

## 一、这节课要解决的真问题

老师做一节课的课件要 2~3 小时，一半时间在排版对齐；做完还"放完就忘"。
本案例要演示：**用"四件套"把需求说清楚，让 WorkBuddy 直接产出一份下载就能投影的 .pptx**，并且用"骨架→血肉→打磨"三步把"一次到位"变成"边用边改"。

## 二、讲什么（示范内容）

- 主题：五年级数学《分数的加法和减法》第2课时·**异分母分数加减法**
- 学情：已学同分母加减、约分、通分；**容易在找公分母上出错**
- 产出：6~8 页课堂课件，覆盖导入 / 例题讲解 / 易错点提醒 / 随堂练习

## 三、怎么讲（复刻时的执行顺序 = 手册顺序）

| 步 | 手册原话 | 本案例怎么做 |
|---|---|---|
| 1 | 四件套指令 | 写完整指令（我是谁/要什么/有啥料/要啥样），得到"第一版" |
| 2 | 计划模式·骨架 | 出 `大纲.md`：页号/页面名/类型/角色/版式/核心内容，**不展开全文** |
| 3 | 血肉 | 出 `逐页内容.md`：展开每页实际文字与公式 |
| 4 | 打磨 | 出成品 pptx，渲染成图逐页看，**哪里不对点哪里**，记录改动与原因 |
| 5 | 交付 | `最终产物/分数加减法.pptx`，下载就能用 |

## 四、四件套指令（本案例实际使用的）

> "我是五年级数学老师，要一节'分数加减法'的课堂课件，知识点是异分母分数相加减。学生刚学完通分，容易在找公分母上出错。要6页左右：导入、例题讲解、易错点提醒、随堂练习。风格简洁清楚，适合课堂投影，生成PPT。"
> （手册原文，第04章"形态一"小节"直接复制"段，逐字照抄）

补充约束（本机复刻必需，非手册原文）：
- 浅底深字，正文 ≥18pt，标题 ≥32pt（课堂投影后排可读）
- 分数一律用**上下结构**渲染，不用斜杠 `1/2`（避免后排误读）
- 不生图（本机无 OpenAI key），视觉靠形状/分数条/排版
