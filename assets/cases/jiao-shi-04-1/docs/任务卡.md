## 二、内容必须覆盖（手册与备课素材共同约束）

- **导入**：分蛋糕生活情境，1/2 + 1/3 怎么算（备课素材"教学过程框架·（一）导入"）
- **例题讲解**：异分母相加 + 异分母相减，三步"通分→计算→约分"
  - 例1：1/2 + 1/3 = 3/6 + 2/6 = 5/6
  - 例2：3/4 − 1/6 = 9/12 − 2/12 = 7/12
- **易错点提醒**（备课素材"七、易错点提醒"三条）
  1. 通分时找错公分母（不是最小公倍数）
  2. 计算完忘记约分，结果不是最简分数
  3. 只通分了分母，忘了分子也相应变化
- **随堂练习**：基础关 3 题 + 挑战关 2 题，含答案揭晓
  - 1/3 + 1/6 = 1/2 ； 2/5 + 3/10 = 7/10 ； 7/8 − 1/4 = 5/8 ； 5/6 − 2/3 = 1/6 ； 应用 1/4 + 1/3 = 7/12
